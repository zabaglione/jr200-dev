# CORNER CROWN

8×8の盤で相手の石を自分の石で挟んで裏返し、双方が置けなくなったときに石が多ければ勝つ
対戦ボードゲームです。JR100devの`CORNER CROWN 1.5.1`（`games/corner_crown/rules.py`）を仕様として、
JR-200向けにM6800アセンブリで作り直しました。合法手、8方向の石返し、パス、相手の思考、終局判定は
上流と同じです。

## 目的と勝敗

- あなたは白（`O`、塗りつぶし）、相手は黒（`@`、中央に穴）です。
- 相手の石を縦・横・斜めに挟める場所にだけ置けます。挟んだ石はすべて裏返ります。
- 置ける場所がないときは`RETURN`でパスし、相手が続けて打ちます。
- 双方とも置けなくなったら終局です。石が多ければ勝ち、同数または少なければ負けです。
- 相手は「最も多く返せる場所」を選び、同数なら盤の左上から近い方を選びます。乱数は使いません。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `A` / `S` / `D` | 置く場所を選ぶ（端では止まる） |
| `RETURN` | 石を置く／置けないときはパス。置けない場所なら警告音だけで何も変わらない |
| `SPACE` | やり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定、`SPACE`で取消 |
| `CTRL+C` | ゲームの終了処理を通してBASICへ戻る。Webエミュレータでは`CTRL+SHIFT+C`で送る |

石は1枚ずつ、面が細くなって側面を見せ、反対の面が開く5段階で裏返ります。相手の手番と演出の
あいだに押したキーは捨てられるか1回分にまとまるため、盤が止まってから次のキーを押してください。
ジョイスティックには対応していません。
Webエミュレータの`Escape`キーはJR-200の`BREAK`（NMI）です。ゲームの終了処理を通らず、
画面が復元されないため、終了操作には使わないでください。

## 最初の目標と序盤のコツ

- 盤の四隅（黄色の`◆`）に置いた石は二度と裏返りません。角を取ることが最初の目標です。
- 相手は目先の枚数だけを見るので、角のすぐ隣に相手を誘うと角を取れる機会が生まれます。
- 序盤は返す枚数を少なく抑え、相手が置ける場所を減らすと終盤に有利です。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAMは起動前の状態に戻ります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`（専用stackを含む）です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/expectations.json`のRAM期待値は`tests/model.py`（上流ルールのPythonモデル）が計算した値です。
`synthetic-win`は決定的な相手に対して探索で見つけた30手の勝ち筋（角4つ、39対25）、
`synthetic-pass-lose`は2回のパスを含む負け筋（10対54）を最後まで打ちます。
