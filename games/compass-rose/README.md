# COMPASS ROSE

最後に測った方角と距離帯を手がかりに、埋まった遺物を掘り当てるゲームです。全10地点です。
JR100devの`COMPASS ROSE 3.0.0`（`games/compass_rose/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。岩の列、遺物の位置、方角と距離帯、補給、測定と掘る回数は上流と同じです。

## 目的と勝敗

- 8×8の荒れ地を歩き、遺物のあるマスで掘ると発見してクリアです。
- 開始時に1回だけ無料で測定します。`X`で追加の測定ができます（4回まで、補給2）。
  測定結果は測った場所のもので、歩いても自動では変わりません。
- BEARINGは遺物の方角（N/S/W/E）、距離帯は上下左右の合計でNEAR（0〜2）、MID（3〜5）、FAR（6以上）です。
- 1歩ごとに補給（STEPS）が1減り、0になると失敗（`OUT OF TRAVEL SUPPLIES`）です。岩と端にぶつかっても補給は減りません。
- 掘り外すとDIGSが1減り、3回外すと失敗（`NO DIGS REMAIN`）です。
- 10地点をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `A` / `S` / `D` | 上・左・下・右へ1歩 |
| `X` | 今いる場所で測定する（補給2） |
| `RETURN` | 掘る |
| `SPACE` | この地点のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

測定の輪が広がる演出、掘る演出が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- 最初の測定の方角で、岩の列の切れ目（毎回位置が変わる）を探して進みます。
- 距離帯の境目を越えたところで測り直すと、候補が大きく絞れます。
- 掘るのは候補が1マスに絞れてからにします。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ホ短調の3声の行進曲（音源F・D・Cを同時に使用、ループ） |
| 歩く・掘る | 短い音（音源C） |
| 測定 | 3段に上がる音（音源C） |
| 岩にぶつかる・掘り外す | 低いブザー（音源C） |

| クリア | 3声のホ長調アルペジオ |
| 失敗 | 3声の下がる音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
各地点へは、モデルの探索（`path()`）で求めた岩を避ける最短経路で進みます。
