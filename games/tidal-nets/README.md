# TIDAL NETS

潮の流れを読んで網を投げ、9回の投網と12本のロープで漁獲の目標（QUOTA）を目指す漁のゲームです。
全3回の漁です。JR100devの`TIDAL NETS 3.0.0`（`games/tidal_nets/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。潮の向きと強さ、浅い群れと深い群れの流され方、網の幅とロープ、
目標の数は上流と同じです。

## 目的と勝敗

- 網を置く列を選んで投げると、浅い群れ（SHOAL）は潮の分だけ、深い群れ（DEEP）は2倍流されてから網に掛かります。
- 網の下に来た浅い群れは+2、深い群れは+4、両方なら+6です。
- 細い網（FINE NET）は1列でロープ1、広い網（WIDE NET）は隣の2列でロープ2です。
- 漁獲が目標（1回目30、2回目33、3回目36）に達するとクリアです。9回投げ終えるかロープが0になると
  失敗（`THE FISHING TRIP MISSED QUOTA`）です。
- 3回の漁をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| key | 動作 |
| --- | --- |
| `A` / `D` | 網を置く列を選ぶ（8列で循環） |
| `W` / `S` | 細い網と広い網を切り替える（次の投網でも続く） |
| `RETURN` | 網を投げる |
| `SPACE` | この漁のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

網が沈み、2つの群れが流され、漁獲が引き上げられる演出が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- TIDEの矢印（`>`は右、`<`は左）と数字（強さ）から、群れが止まる列を先に計算します。
- 2つの群れが隣り合う列に来る投網では、広い網で両方（+6）を狙います。
- ロープは12本です。広い網ばかりだと6回で尽きます。

| --- | --- | --- |
| 浅い群れ（SHOAL +2） | 黄 | 魚 |

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ニ長調の3声の舟歌（音源F・D・Cを同時に使用、ループ） |
| 網を投げる・幅を変える | 水音（音源C） |
| 漁獲 | 3音の効果音（音源C） |
| 空振り・ロープ不足 | 低い2音（音源C） |
| クリア | 3声のニ長調アルペジオ |
| 失敗 | 3声の下がるニ短調の音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
各漁の投網は、目標に届く手順をモデルの探索で求めています。
