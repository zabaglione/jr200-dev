# GRAVITY WELL

部屋を傾けて2つの球を同時に転がし、2つの受け口（菱形）の両方に球を入れるパズルです。全40の井戸です。
JR100devの`GRAVITY WELL 1.7.1`（`games/gravity_well/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。40の井戸（上流`levels.json`）、傾けたときの球の転がり方（最大6マス、上流と同じ順序で1マスずつ）、2つの受け口、任意のルーン、手数とPAR、星の評価は上流と同じです。
ステージマップ、各井戸の最高評価、パスワードは、上流の評価つきキャンペーンを写したSDKの`sdk/ranked.inc`で動きます（操作はFROST STEPSと共通です）。

## 目的と勝敗

- `W` / `A` / `S` / `D`で部屋を傾けると、2つの球が同時にその向きへ転がり、壁かもう一方の球に当たって止まります。
- 2つの受け口の両方に球が止まるとクリアです。受け口の上で止まる必要があり、通り過ぎても入りません。失敗はありません。
- ルーンはどちらの球が通っても取れます。
- 球が1マスでも動いた傾きが1手です。どちらの球も動かない傾きは数えません。PAR以内なら星2つ、さらにルーンを2つとも取れば星3つ、PARを超えると星1つです。
- 各井戸の最高評価（BEST）は、やり直し・タイトル・マップへ戻っても残ります。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 選んでいる井戸を遊ぶ |
| タイトル | `F` | ステージマップ |
| タイトル | `X` | パスワード入力 |
| タイトル | そのほか | 説明 |
| 井戸 | `W` / `A` / `S` / `D` | 部屋を傾ける |
| 井戸 | `SPACE` | やり直し（確認あり） |
| 井戸 | `F` | マップ（確認あり） |
| クリア後 | `RETURN` | 次の井戸 |
| クリア後 | `SPACE` | やり直し |
| クリア後 | `F` | マップ |
| マップ | `W` / `A` / `S` / `D` | 井戸を選ぶ |
| マップ | `RETURN` | 遊ぶ |
| マップ | `SPACE` | タイトル |
| マップ | `X` | パスワード |
| パスワード | 英字 | 入力（`ACDEFGHJKMNPQRTW`、大文字・小文字どちらでも） |
| パスワード | `-` / `BACKSPACE` | 1文字消す |
| パスワード | `RETURN` | 読み込む |
| パスワード | `X` | 取り消す |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 2つの球は必ず一緒に動きます。片方を壁際で止めておき、もう片方だけを進める手順が鍵になります。
- 球同士もぶつかって止まるので、並んだ球は位置関係を組み替える道具になります。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`、`tests/ranked_model.py`は上流の評価つきキャンペーンとパスワードを写したPythonモデルです。
`tests/expectations.json`のRAM期待値（盤面、球と転がり元、評価、`$4760`の最高評価表）はこれらが計算します。
各井戸は上流`solutions.json`（星3つ）と`challenges.json`のクリア手順（星2つ）を再生します。40の井戸は1-20、21-30、31-40の3回に分け、2回目以降はパスワードで再開します（1回の実行の上限サイクル数のため）。
