# NIGHT SWARM

8方向に動く船で、四方の入口から迫る群れを自動射撃と範囲パルスで倒し続けるアクションゲームです。全6波です。
JR100devの`NIGHT SWARM 3.0.0`（`games/night_swarm/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。入口の予告と順番、敵の出現間隔と装甲、3 tickごとの行進、4 tickごとの自動射撃、
パルスの範囲と再使用までの時間、4体ごとに残る回収物、船体は上流と同じで、上流の1 tickをこの版の1 tickとして移しています。

## 目的と勝敗

- 8×8の盤で船を動かします。`W`/`X`（または`S`）で上下、`A`/`D`で左右、`Q`/`E`/`Z`/`C`で斜めに1マス動きます。
- 敵は盤の外周の入口（水色の渦、次の出現位置）から現れ、3 tickごとに船へ1マス近づきます。装甲のある敵（赤）は2回、ない敵（紫）は1回で倒れます。
- 4 tickごとに、距離2以内の最初の敵へ自動で撃ちます。`RETURN`で距離3以内の全員に当たるパルスを出します（その後8 tick使えません）。
- 敵が船に重なると、何体でも船体（HULL）を1失います。4つ失うと失敗です。
- 4体倒すごとに回収物（緑）が残ります。拾うと船体が1回復し（最大4）、パルスがすぐ使えます。
- 12体＋（波番号−1）×2体を倒すと波のクリアです。6波目をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 1波目から始める |
| タイトル | `P` | 1波目の自動デモ（`DEMO`表示） |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| 波 | `W` / `A` / `D` / `X`（`S`） | 上・左・右・下へ1マス |
| 波 | `Q` / `E` / `Z` / `C` | 左上・右上・左下・右下へ1マス |
| 波 | `RETURN` | パルス（`PULSE READY`のとき） |
| 波 | `SPACE` | やり直し（確認あり） |
| クリア後 | `RETURN` | 次の波 |
| 失敗後 | `RETURN` | やり直し確認 |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

上流の8方向入力（QWE/AD/ZXC）に合わせ、`X`を下にしています。`S`も下として使えます。

## 最初の目標と序盤のコツ

- 自動射撃は距離2以内にしか届きません。敵が集まったらパルスでまとめて倒します。
- 入口の渦を見て、次の敵が来る側から少し離れておきます。

## 速さ

上流は10/60秒（約0.17秒）に1 tickです。この版は、固定エミュレータで1 tickが約20万cycle（約0.15秒、描画を含む）です。
移動、行進、射撃、パルス、被弾と撃破の演出の間はtickが止まります。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$5FFF`（専用stackと自己試験の結果を含む）です。

## 開発と自己試験

tickとキーの時間関係はcycleに依存するため、ルールの一致はプログラム内の自己試験で確かめます
（`sdk/selftest.inc`）。タイトルで`T`を押すと、`tests/selftest.py`の27件のfixture（状態を置いて1 tickまたは1操作）と、
6波それぞれの入力スクリプト（tickに同期した操作列）での通し遊びを実行し、結果を`$5000`以降へ書き出します。
`tests/expectations.json`の期待値は`tests/model.py`（上流`rules.py`のPythonモデル）と`tests/selftest_model.py`が計算した値です。
スクリプトはモデル上で1 tickごとに次の手を先読みで選んで作り、6波すべてを船体を失わずにクリアします。
`P`の自動デモは1波目のスクリプトを通常の速さで再生します。
`src/selftest.inc`は`python3 tests/make_selftest.py night-swarm`で生成します。
