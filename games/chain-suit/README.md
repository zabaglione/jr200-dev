# CHAIN SUIT

5枚の手札から最大2枚を引き直して役を作り、3回の手札で合計25点を目指すカードゲームです。1面です。
JR100devの`CHAIN SUIT 1.6.1`（`games/chain_suit/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。配られる数字とスート、引き直しの札、役の判定と点数は上流と同じです。

## 目的と勝敗

- 各手札で最大2回、選んだ札を引き直せます。`RETURN`で採点して次の手札へ進みます。
- 役なし3点、ワンペア8点、同じ数字の組が複数できる役（ツーペア、スリーカード、フルハウス、フォーカード、ファイブカード）16点、
  5枚が同じスートなら25点です。
- 3回の手札の合計が25点以上ならクリア、足りなければ失敗（`TOTAL BELOW 25`）です。
- クリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

札は乱数ではなく、手札の回数と引き直しの累計回数から決まります。

## 操作

| key | 動作 |
| --- | --- |
| `A` / `D` | 札を選ぶ（5枚で循環） |
| `W` | 選んだ札を引き直す（各手札2回まで） |
| `RETURN` | 採点して次の手札へ |
| `SPACE` | やり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

引き直す札が細くなって側面を見せ、新しい札として開く演出と、採点時の印の点滅と約2秒の間が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- 最初の手札は役なしです。引き直した札の数字とスートは、引き直しの累計回数で変わります。
- 1回目の手札で2回とも引き直すと、次の手札の配り方も変わります。
- 25点のスートそろいは強力ですが、2回の引き直しでは難しい手札もあります。ペアを確実に取るのも手です。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ハ長調の3声の軽快な曲（音源F・D・Cを同時に使用、ループ） |
| 引き直し | 札をめくる2音（音源C） |
| 採点 | 上がる4音（音源C） |
| クリア | 3声のハ長調アルペジオ |
| 失敗 | 3声の下がる音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
引き直しの手順は、3回の手札の引き直しの選び方をすべて調べた最高点の手順（`plan()`、48点）です。
