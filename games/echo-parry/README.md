# ECHO PARRY

騎士の攻撃に合わせて上段・下段の構えを取り、攻撃の瞬間に受け流して反撃する決闘のアクションゲームです。全6戦です。
JR100devの`ECHO PARRY 2.0.0`（`games/echo_parry/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。構え→攻撃→隙のリズム、受け流しの時間枠、連鎖と2点反撃、後退、
3戦目からのフェイント、攻撃の型の表（上流`game.json`の`pattern`）は上流と同じで、上流の1 tickをこの版の1 tickとして移しています。

## 目的と勝敗

- 騎士は`READY`（待ち）→`ATTACK`（攻撃、2 tick）→`RECOVERY`（隙）を繰り返します。攻撃は上段か下段です。
- `W`で上段、`S`で下段に構えます。攻撃中に騎士と同じ段で`RETURN`を押すと受け流して反撃し、鎧（ARMOR）を削ります。
- 攻撃の後半（`COUNTER!`表示中）の受け流しと、3回目の連鎖（CHAIN 3）は2点です。
- 段が違う、攻撃の前、または攻撃を受け流さずに終わると、ハート（HEARTS）を1つ失います。4つ失うと失敗です。
- `A`は後退です。その攻撃を避けますが連鎖は0に戻ります。
- 3戦目からは3回に1回、`FEINT`で攻撃の段が入れ替わります。5戦目からは攻撃が早く来ます。
- 鎧を0にすると勝ち、6戦目に勝つと`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 1戦目から始める |
| タイトル | `P` | 1戦目の自動デモ（`DEMO`表示） |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| 決闘 | `W` / `S` | 上段／下段の構え |
| 決闘 | `RETURN` | 受け流し |
| 決闘 | `A` | 後退 |
| 決闘 | `SPACE` | やり直し（確認あり） |
| クリア後 | `RETURN` | 次の決闘 |
| 失敗後 | `RETURN` | やり直し確認 |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- `READY`の間に騎士の段を見て構え、`COUNTER!`が出てから`RETURN`を押すと2点になります。
- 1回の攻撃で受け流せるのは1回です。

## 速さ

上流は12/60秒（0.2秒）に1 tickです。この版は、固定エミュレータで1 tickが約27万cycle（約0.2秒、描画を含む）です。
刃が飛ぶ間と反撃・被弾・フェイントの演出の間はtickが止まります。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$5FFF`（専用stackと自己試験の結果を含む）です。

## 開発と自己試験

tickとキーの時間関係はcycleに依存するため、ルールの一致はプログラム内の自己試験で確かめます
（`sdk/selftest.inc`）。タイトルで`T`を押すと、`tests/selftest.py`の21件のfixture（状態を置いて1 tickまたは1操作）と、
6戦それぞれの入力スクリプト（tickに同期した操作列）での通し遊びを実行し、結果を`$5000`以降へ書き出します。
`tests/expectations.json`の期待値は`tests/model.py`（上流`rules.py`のPythonモデル）と`tests/selftest_model.py`が計算した値です。
スクリプトは攻撃の段に構えて`COUNTER!`の間に受け流す手順で、6戦すべてにハートを失わず勝ちます。
`P`の自動デモは1戦目のスクリプトを通常の速さで再生します。
`src/selftest.inc`は`python3 tests/make_selftest.py echo-parry`で生成します。
