# SAND RESCUE

砂漠の畑で、少しずつたまる水槽の水を3本の水路（A・B・C）のどれかへ流し、作物を実らせる水やりのゲームです。全6面です。
JR100devの`SAND RESCUE 2.0.0`（`games/sand_rescue/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。面ごとの水路の表（近い作物・遠い作物の必要量、ひび割れの吸水量、位置）、
水槽の補給と溢れ、ひび割れでの損失、面の目標点、残った水と合計点の次の面への持ち越し、最終面の勲章は上流と同じで、
上流の1 tickをこの版の1 tickとして移しています。

## 目的と勝敗

- 貯水（`WATER`）から一定時間ごとに1ずつ水槽（`TANK`、最大9）へ水が入ります。満杯のときに入る分は溢れて失われます（`TANK OVERFLOW!`）。
- `A` / `D`で水門を選び、`RETURN`で水槽の水を全部その水路へ流します（`POUR`は流れている量）。流れている間は次を流せません。
- 水は水路を1マスずつ下ります。近い作物に着くと必要量まで（1回最大5）飲み、実ると3点です。
  その先のひび割れは数字の分だけ水を吸い（`WATER SOAKED INTO SAND`）、遠い作物は必要量の2倍の点（6〜10点）です。残りは流れ去ります。
- 作物の下の`c/b`は与えた量／必要量、右の`+`は実ったときの点です。
- 目標点（14／17／19／21／24／26）に届き水が流れていなければ、`W`で面を終えられます（`READY`表示）。
  残った貯水と水槽の水、合計点は次の面へ持ち越します。
- 貯水も水槽も流れる水もなくなったとき目標点に届いていなければ失敗です（`NO WATER LEFT FOR THE HARVEST`）。
  失敗ややり直しのあとは1面から始め直します。6面を終えたとき合計140点以上で金、130点以上で銀、それ未満は銅です。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 1面から始める |
| タイトル | `P` | 1面の自動デモ（`DEMO`表示） |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| 面 | `A` / `D` | 水門を選ぶ |
| 面 | `RETURN` | 水槽の水を流す |
| 面 | `W` | 目標点に届いたら面を終える |
| 面 | `SPACE` | 1面からやり直し（確認あり） |
| クリア後 | `RETURN` | 次の面 |
| 失敗後 | `RETURN` | 1面からやり直す |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 水槽を満杯近くまでためてから流すと、1回で近い作物と遠い作物の両方へ届きます。ただし満杯のまま待つと溢れます。
- ひび割れの小さい水路ほど損が少なく、遠い作物は点が大きいので、点÷水の良い水路を選びます。
- 水は面をまたいで持ち越すので、目標点に届いたら早めに`W`で終えると後の面が楽になります。

## 速さ

上流は12/60秒（0.2秒）に1 tickです。この版は、固定エミュレータで1 tickが約28万cycle（描画を含み、約12.5フレーム）です。
放水・水やり・実り・ひび割れの演出の間はtickが止まります。上流に乱数はありません。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$5FFF`（専用stackと自己試験の結果を含む）です。
次の面へ持ち越す値は面の状態の外（`$46A0`）に置きます。

## 開発と自己試験

tickとキーの時間関係はcycleに依存するため、ルールの一致はプログラム内の自己試験で確かめます
（`sdk/selftest.inc`）。タイトルで`T`を押すと、`tests/selftest.py`の21件のfixture（状態を置いて1 tickまたは1操作。
面の終了と持ち越し、失敗後の1面への戻りを含む）と、6面を1つの通しとして続けて遊ぶ入力スクリプト（tickに同期した操作列）を実行し、
結果を`$5000`以降へ書き出します。
`tests/expectations.json`の期待値は`tests/model.py`（上流`rules.py`のPythonモデル）と`tests/selftest_model.py`が計算した値です。
スクリプトは水槽がたまるのを待って点÷水の良い水路へ流す手順で作り、6面すべてをクリアします（合計131点、銀）。
`P`の自動デモは1面のスクリプトを通常の速さで再生します。
`src/selftest.inc`は`python3 tests/make_selftest.py sand-rescue`で生成します。
