# CHRONO BREACH

動いたときだけ時間が進む、20区画の戦術パズルです。衛兵の射線を読み、踏み込んでの攻撃と4マスの射撃で全員を倒し、出口へ抜けます。
JR100devの`CHRONO BREACH 1.6.1`（`games/chrono_breach`）を仕様として、JR-200向けにM6800アセンブリで作り直しました。
上流はJR-100向けの手書きアセンブリで、規則は上流`src/turn.asm`と、それを独立に写した上流`solve.py`に従います。
この版の`tests/model.py`は上流`solve.py`と全323行動で同じ結果になることを確かめた規則に、上流`src/main.asm`のメニューと確認を加えた検証用モデルです。
20の区画、弾数、目標行動数は上流の`levels.json`、通しの手順は上流の`solutions.json`です。

## 目的と勝敗

- `W`/`A`/`S`/`D`で1マス動きます。移動、射撃、待機のたびに、飛んでいる弾がすべて1マス進みます。止まっている間は何も動きません。
- 壁に向かって押すと向きだけが変わり、時間は進みません。
- 衛兵は3行動ごとに、向いている方向へ弾を撃ちます（最初の行動で最初の一斉射撃）。赤い点がその射線で、右の`FIRE IN`は次の射撃までの行動数です。
- 衛兵のマスへ踏み込むと倒せます。`F`は向いている方向へ4マス撃ち、壁か最初の衛兵で止まります。弾がないときは撃てず、時間も進みません。
- 弾は壁で消え、主人公や衛兵（味方の弾でも）に当たると倒します。弾のあるマスへ踏み込んでも倒されます。
- 衛兵を全員倒すと出口が開き、そこへ着けば区画の突破です。行動数が目標（`TARGET`）以内なら`ACE`と表示します。
- 弾に当たると失敗です（`CAUGHT IN THE CROSSFIRE`）。20区画を突破すると結果画面にやり直しの回数を表示します。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 始める |
| タイトル | そのほか | 説明 |
| 区画 | `W` / `A` / `S` / `D` | 移動（壁なら向きだけ変える） |
| 区画 | `F` | 撃つ |
| 区画 | `X` | 待つ |
| 区画 | `RETURN` / `SPACE` | 戦術メニュー |
| メニュー | `W` / `S` | FIRE／WAIT／RESET／TITLE／BACKを選ぶ |
| メニュー | `A` / `D` | 照準を北・南・西・東へ回す（時間は進まない） |
| メニュー | `RETURN` / `SPACE` | 決定／閉じる |
| RESET?・TO TITLE? | `A` / `D`、`RETURN` | YES／NO（最初はNO）、決定 |
| 突破後 | `RETURN` | 次の区画、最後は結果画面 |
| 失敗後 | `RETURN` | やり直すか確認（`D`でYES） |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 最初の区画FIRST CONTACTでは、開始位置が西を向く衛兵の射線上にあります。まず上へ逃げ、弾の列の上を東へ進みます。
- 射線の外から撃つには、メニューで照準を回してから`FIRE`を選びます。上流の手順は11行動（目標13）です。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`（専用stackを含む）です。

## 開発と検証

ターン制なので、各規則と通しの成功・失敗を固定エミュレータのキーreplayで確かめます。
`tests/expectations.json`の期待値は`tests/model.py`が計算した値で、エミュレータの出力を写したものではありません。
`synthetic-all-sectors`は上流`solutions.json`の手順で20区画を通します（向きと違う方向への射撃は、メニューで照準を回してから撃ちます）。
キーの間隔は1キー25万cycleに、演出1フレームあたり7万cycleを足します。
`src/levels.inc`は`tests/make_levels.py`が`tests/levels.py`から生成します。
上流のタイトル画面での区画選択は、この版にはありません（常に最初の区画から始めます）。
