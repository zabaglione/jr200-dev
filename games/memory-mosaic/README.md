# MEMORY MOSAIC

16枚の札を2枚ずつめくり、同じ絵柄の組を8組すべてそろえる神経衰弱です。全10面です。
JR100devの`MEMORY MOSAIC 3.0.0`（`games/memory_mosaic/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。札の混ぜ方、めくり方、連続一致（CHAIN）、不一致の上限は上流と同じです。

## 目的と勝敗

- 札を1枚めくり、もう1枚めくって同じ絵柄なら組がそろい、表のまま残ります。
- 違う絵柄なら不一致（MISSES）が1つ増えます。次の`RETURN`で2枚とも裏へ戻ります。
- 8組そろえるとクリアです。不一致が上限（1〜3面12、4〜6面11、7〜9面10、10面9）に達すると
  失敗（`TOO MANY PAIRS DID NOT MATCH`）です。
- 10面をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

札の並びは、面が始まった時点のタイトル曲の進み具合（上流の`entropy()`に当たる値）と面の番号から決まります。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `A` / `S` / `D` | 札を選ぶ（端では止まる） |
| `RETURN` | 札をめくる。2枚めくった後は、次の`RETURN`で確かめ終える |
| `SPACE` | この面のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

札が返る演出と、一致の光が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- まだ見ていない札を1枚めくり、見覚えのある絵柄ならその相手をめくります。
- 色と形の両方で絵柄を覚えると、取り違えが減ります。
- 続けてそろえるとCHAINが伸びます。不一致で0に戻ります。

## 画面（色と記号）

| 絵柄 | 色 | 形 |
| --- | --- | --- |
| 0 | 赤 | 円 |
| 1 | 緑 | 四角の枠 |
| 2 | 黄 | 山形 |
| 3 | 水色 | ひし形 |
| 4 | 紫 | 星 |
| 5 | 白 | ハート |
| 6 | 白地に青 | 十字 |
| 7 | 黄地に黒 | 輪 |

裏向きの札は青の網目、返る途中の札は白です。`MATCHED!`は緑、`MISMATCH`は赤で表示します。
右側にそろった組（PAIRS）、不一致と上限（MISSES）、連続一致（CHAIN）を表示します。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ト長調の3声の曲（音源F・D・Cを同時に使用、ループ） |
| 札を返す | 短いクリック（音源C） |
| 一致 | 3音の効果音（音源C） |
| 不一致 | 低い2音（音源C） |
| クリア | 3声のト長調アルペジオ |
| 失敗 | 3声の下がるト短調の音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルです。面の開始時に取った値（origin）だけは
エミュレータの実行から`$4720`の記録として受け取り、札の並びを含むほかのRAM期待値はモデルが計算します。
