# FROST STEPS

氷の部屋を壁まで滑り、ダイヤ形のクリスタルをすべて集めるパズルです。全40部屋です。
JR100devの`FROST STEPS 1.7.2`（`games/frost_steps/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。40部屋（上流`levels.json`）、壁まで滑る動き、クリスタル、任意のルーン、手数とPAR、星の評価は上流と同じです。
ステージマップ、各部屋の最高評価、パスワードは、上流の評価つきキャンペーン（`rankedCampaign`）を写したSDKの`sdk/ranked.inc`で動きます。

## 目的と勝敗

- 向きを選ぶと、壁か盤の端に当たるまで滑ります。実際に滑れた1回が1手です（動けなかった入力は数えません）。
- 滑る途中で通ったクリスタル（菱形）とルーン（丸）を拾います。クリスタルをすべて拾うとクリアです。失敗はありません。
- 評価は星3つまでです。PAR以内なら星2つ、さらにルーンを2つとも拾えば星3つ、PARを超えると星1つです。
- 各部屋の最高評価（BEST）は、やり直し・タイトル・マップへ戻っても残ります（電源を切ると消えます）。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 選んでいる部屋を遊ぶ |
| タイトル | `F` | ステージマップ |
| タイトル | `X` | パスワード入力 |
| タイトル | そのほか | 説明 |
| 部屋 | `W` / `A` / `S` / `D` | 上・左・下・右へ滑る |
| 部屋 | `SPACE` | やり直し（確認あり） |
| 部屋 | `F` | ステージマップ（確認あり） |
| クリア後 | `RETURN` | 次の部屋 |
| クリア後 | `SPACE` | やり直し |
| クリア後 | `F` | マップ |
| マップ | `W` / `A` / `S` / `D` | 部屋を選ぶ（端は反対側へ回る） |
| マップ | `RETURN` | 遊ぶ |
| マップ | `SPACE` | タイトル |
| マップ | `X` | パスワード |
| パスワード | 英字 | 入力（`ACDEFGHJKMNPQRTW`の16文字、大文字・小文字どちらでも） |
| パスワード | `-` / `BACKSPACE` | 1文字消す |
| パスワード | `RETURN` | 読み込む |
| パスワード | `X` | 取り消す |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

パスワードは、タイトルとマップの`PW`の行に出ます。選んでいる部屋と40部屋すべての最高評価を含み、CRCで誤りを検出します。ほかの作品の文字列は受け付けません。

## 最初の目標と序盤のコツ

- 止まれる場所は壁の手前だけです。クリスタルの手前で止まれる壁を探します。
- ルーンを拾う順番まで考えると、PAR以内で星3つになります。
- 最後のクリスタルを拾った滑りでクリアになるので、ルーンは先に拾います。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | 嬰ヘ短調の3声のワルツ（音源F・D・Cを同時に使用、ループ） |
| 滑る | 短い音（音源C） |
| クリスタル・ルーン | 上がる3音（音源C） |
| クリア | 3声の嬰ヘ長調アルペジオ |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`、`tests/ranked_model.py`は上流の評価つきキャンペーンとパスワード（`campaign_runtime.asm`、`password.asm`、`password.py`）を写したPythonモデルです。
`tests/expectations.json`のRAM期待値（盤面、評価、`$4760`の最高評価表）はこれらが計算します。
各部屋は上流`solutions.json`（星3つ）と`challenges.json`のクリア手順（星2つ）を再生します。40部屋は20部屋ずつに分け、後半はパスワードで21部屋目から再開します。
