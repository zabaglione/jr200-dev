# AUCTION HOUSE

鑑定額と相手の入札を読み、6品の競りで持ち金40を増やすゲームです。全3市場です。
JR100devの`AUCTION HOUSE 3.0.0`（`games/auction_house/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。品物の表、市場の乱数、相手が降りる基準、鑑定、目標額は上流と同じです。

## 目的と勝敗

- 1品ごとに`BID +2`・`BID +6`・`INSPECT`・`PASS`から選びます。
- 入札額が相手の限度に届くと落札し、入札額を払って品物の価値を受け取ります（持ち金の上限は99）。
  届かないと相手が+2で応じます。
- `BID +6`（大きな入札）は相手が降りる基準を4下げます。
- `INSPECT`は持ち金1で正確な価値を見せます（1品に1回）。`PASS`はその品を見送ります。
- 6品を終えたときに持ち金が目標（1市場目58、2市場目60、3市場目61）以上ならクリア、足りなければ失敗
  （`THE AUCTION ENDED BELOW TARGET`）です。
- 3市場をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

品物の価値は市場を始めるたびに変わります。上流はJR-100のタイマー（`entropy()`）を種にしますが、
JR-200版はタイトル曲の再生位置を種にします。

## 操作

| key | 動作 |
| --- | --- |
| `A` / `D`（`W` / `S`） | 選択肢を選ぶ（4つで循環） |
| `RETURN` | 決定 |
| `SPACE` | この市場のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

入札、相手の応答、落札の木槌、次の品への切り替えの演出が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- APPRAISALは価値の見積もり幅です。最低額でも利益が出る品は大きな入札で早く落札します。
- 見積もり幅が広い品は、持ち金1で鑑定してから決めます。
- 利益が出ない品は`PASS`で見送ります。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ヘ長調の3声のラグタイム（音源F・D・Cを同時に使用、ループ） |

| 持ち金不足 | 低いブザー（音源C） |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
エミュレータから取るのは各市場の開始時の種（`origin`、`$4720`に記録）だけで、ほかの値はすべてモデルの予測です。
各市場の選択は、その種に対してモデルの探索（`plan()`）で求めています。全256通りの種で3市場とも目標に届く手順があることもテストで確認します。
