# IRON SCRIPT

8種類の命令を並べてロボットのプログラムを組み、扉・見張り・レーザーを越えて端末（ひし形）まで動かすパズルです。全24部屋です。
JR100devの`IRON SCRIPT 2.0.1`（`games/iron_script/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。24部屋（上流`levels.json`）、12枠のプログラム、1 tickに1命令の実行、
扉とスイッチ、見張りと装甲の見張り、1手ごとに切り替わるレーザー、直前2命令の繰り返し（L）、止まった理由は上流と同じです。

## 目的と勝敗

- 部屋ごとに使える枠の数（PROGRAM）と弾の数（AMMO）が決まっています。枠に命令を入れて`RETURN`で実行します。
- 命令は`.`待つ、矢印4つ（向きを変えて1マス進む）、`F`前へ撃つ、`U`スイッチを使う、`L`直前の2命令をもう一度ずつ、の8種類です。
- 壁・見張り・閉じた扉にぶつかる、弾がない、スイッチ以外で`U`、`L`が続く・先頭にある、レーザーが点いているマスにいる、最後まで端末に着かない、のどれかで実行が止まり、原因が下に出ます。
- 止まっても部屋は最初に戻り、プログラムはそのまま残ります。直して再実行します。
- 端末に着くと部屋のクリアです。24部屋目をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 1部屋目から始める |
| タイトル | `P` | 1部屋目の自動デモ（`DEMO`表示） |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| 編集中 | `A` / `D` | 枠を選ぶ |
| 編集中 | `W` / `S` | 命令を替える |
| 編集中 | `RETURN` | 実行する |
| 実行中 | `RETURN` | 止める |
| 部屋 | `SPACE` | プログラムを消してやり直し（確認あり） |
| クリア後 | `RETURN` | 次の部屋 |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 1部屋目は、スイッチで扉を開け、見張りを撃ってから端末へ進みます。
- レーザー（赤）は1手ごとに点いたり消えたりします。右の`LASER ON!`／`LASER OFF`は次の1手の状態です。`.`で待って合わせます。

## 速さ

上流は20/60秒（約0.33秒）に1命令です。この版は、固定エミュレータで1命令が約50万cycle（約0.37秒、描画と動きの演出を含む）です。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$3FFF`、作業領域は`$4000-$73FF`（専用stackと自己試験の結果を含む）です。
24部屋と自己試験の表で8Kを超えるため、ほかの移植より作業領域を1ページ上に置いています。

## 開発と自己試験

実行は1 tickに1命令で、キーは実行の前後にしか読まないため、結果はtickの時間に依存しません。
タイトルで`T`を押すと、`tests/selftest.py`の31件のfixture（状態を置いて1 tickまたは1操作）と、
24部屋それぞれで上流`solutions.json`のプログラムを編集キーで打ち込んで実行する通し遊びを行い、結果を`$6000`以降へ書き出します
（`sdk/selftest.inc`）。
`tests/expectations.json`の期待値は`tests/model.py`（上流`rules.py`のPythonモデル）と`tests/selftest_model.py`が計算した値です。
`P`の自動デモは1部屋目の打ち込みと実行を通常の速さで再生します。
`src/selftest.inc`は`python3 tests/make_selftest.py iron-script`で生成します。
