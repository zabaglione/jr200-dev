# PEG GARDEN

十字形の庭に並んだ石（ペグ）を、隣の石を飛び越して取り除き、5個以下に減らすパズルです。
JR100devの`PEG GARDEN 1.5.1`（`games/peg_garden/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。庭の形、飛び越しの規則、残り5個の目標は上流と同じです。

## 目的と勝敗

- 石は縦か横に隣の石を1つ飛び越し、その先の空いた穴へ移ります。飛び越された石は取り除かれます。
- 残りの石が5個以下になるとクリア（`CLEAR`）です。1面だけで、クリア後は`ALL STAGES CLEAR`になります。
- 失敗はありません。動けなくなったら`SPACE`で庭を最初に戻します。
- 四隅の岩（青）は動かせず、着地にも使えません。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `A` / `S` / `D` | 位置を選ぶ（端では止まる） |
| `RETURN` | 石を選び、次に着地する穴を選ぶ。飛べない場所なら選択を取り消す |
| `SPACE` | 庭を最初に戻す確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

タイトルで`RETURN`以外の操作キーを押すと遊び方の画面になります。

## 最初の目標と序盤のコツ

- 最初の1手は、中央の穴へ上下左右のどれかから飛び込むことしかできません。
- 端の石を先に中央へ寄せ、最後に残る石が離れ離れにならないようにします。
- 15回飛べば残りは5個です。

## 画面（色と記号）

| もの | 色 | 形 |
| --- | --- | --- |
| 石 | 黄 | 丸い石 |
| 選んだ石 | 紫 | 四角い枠付きの石 |
| 空いた穴 | 黒 | 縁のある穴 |
| 岩（四隅） | 青 | ごつごつした岩 |
| 飛んでいる石 | 黄（背景は黒） | 1段上に浮いた石 |

庭は緑の芝の上に描き、カーソル`>`は白です。色が分からなくても形で区別できます。
右側に残りの石（REMAIN）と目標（TARGET）を表示します。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ト長調の3声の曲（音源F・D・Cを同時に使用、ループ） |
| 石を選ぶ | 短いクリック（音源C） |
| 着地 | 2音の効果音（音源C） |
| クリア | 3声のト長調アルペジオ |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
