# ORBIT DODGE

惑星を回る2本の軌道の上で船を動かし、光線の標的を避けながら宝石を集めるアクションゲームです。全6宙域です。
JR100devの`ORBIT DODGE 3.0.0`（`games/orbit_dodge/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。8つの位置と内外2本の軌道、波ごとの標的・もう1つの標的・宝石の決まり方、
発射までの時間、宝石の連鎖、船体（HULL）、金の軌道の条件は上流と同じで、上流の1 tickをこの版の1 tickとして移しています。

## 目的と勝敗

- 船は外側か内側の軌道の8つの位置のどこかにいます。`A`/`W`で左回り、`D`/`S`で右回りに1つ動き、`RETURN`で内外の軌道を乗り換えます。
- 各波では標的（紫）が1つ選ばれ、IMPACTの数が0になると惑星から光線が放たれます。標的の位置にいると船体を1失います。発射の直前は標的が赤く光ります。
- 5波目から（3つ目の宙域からは最初から）、もう1つの標的が反対側の軌道にも出ます。
- 発射の瞬間に宝石（黄）の位置にいると宝石を取り、連鎖（1、2、3、3…）をENERGYに加えます。取らなかった波で連鎖は0に戻ります。
- 船体を3つ失うと失敗、12波＋（宙域番号−1）×2波を越えると宙域のクリアです。ENERGYが波の数以上なら`GOLD ORBIT`です。
- 6つ目の宙域をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 1つ目の宙域から始める |
| タイトル | `P` | 1つ目の宙域の自動デモ（`DEMO`表示） |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| 宙域 | `A` / `W` | 左回りに1つ |
| 宙域 | `D` / `S` | 右回りに1つ |
| 宙域 | `RETURN` | 内外の軌道を乗り換える |
| 宙域 | `SPACE` | やり直し（確認あり） |
| クリア後 | `RETURN` | 次の宙域 |
| 失敗後 | `RETURN` | やり直し確認 |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 宝石は必ず標的と同じ軌道の、標的ではない位置に出ます。波が始まったらすぐ宝石へ向かうのが安全です。
- 連鎖を切らさなければ、ENERGYは波の数を大きく上回ります。

## 速さ

上流は14/60秒（約0.23秒）に1 tickです。この版は、固定エミュレータで1 tickが約30万cycle（約0.22秒、描画を含む）です。
移動、光線、被弾と宝石の演出の間はtickが止まります。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$5FFF`（専用stackと自己試験の結果を含む）です。

## 開発と自己試験

tickとキーの時間関係はcycleに依存するため、ルールの一致はプログラム内の自己試験で確かめます
（`sdk/selftest.inc`）。タイトルで`T`を押すと、`tests/selftest.py`の18件のfixture（状態を置いて1 tickまたは1操作）と、
6宙域それぞれの入力スクリプト（tickに同期した操作列）での通し遊びを実行し、結果を`$5000`以降へ書き出します。
`tests/expectations.json`の期待値は`tests/model.py`（上流`rules.py`のPythonモデル）と`tests/selftest_model.py`が計算した値です。
スクリプトは各波の1 tick目に宝石へ移る手順で、6宙域すべてを被弾なし・金の軌道でクリアします。
何もしなければ1つ目の宙域は船体1つを残して越えられるため、失敗は自己試験のfixture（`fire-last-hull`）で確かめます。
`P`の自動デモは1つ目の宙域のスクリプトを通常の速さで再生します。
`src/selftest.inc`は`python3 tests/make_selftest.py orbit-dodge`で生成します。
