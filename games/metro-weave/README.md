# METRO WEAVE

2つの分岐器と停止信号を操り、次々に来る列車を行き先の駅（A・B・C）へ届ける配車のゲームです。全3勤務です。
JR100devの`METRO WEAVE 2.0.0`（`games/metro_weave/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。行き先の山札（乱数）、分岐と停止、自動ブレーキ、ホームの降車待ち、
急行と締め切り、連続配達のボーナス、ハート、目標点と勲章は上流と同じで、上流の1 tickをこの版の1 tickとして移しています。

## 目的と勝敗

- 列車は左から1マスずつ進みます。1つ目の分岐（上）で直進するとA駅、曲がると下の線へ進み、2つ目の分岐で直進するとB駅、曲がるとC駅です。
- `W` / `S`で操作する分岐を選び、`D`で向きを切り替え、`A`でその分岐の停止（`STOP`）／進行（`GO`）を切り替えます。停止中の分岐では列車が手前で待ちます。
- 列車の上と左の一覧に番号と行き先が出ます。行き先どおりの駅に着けば2点（急行は4点）×連続数（最大3）です。
- 違う駅に着く（`WRONG PLATFORM`）か、急行が締め切り（左の`+`と残り）を過ぎる（`EXPRESS LATE`）と、ハートを1失い連続が切れます。
- 着いた駅はしばらく降車中（`BUSY`）で、次の列車は手前で待ちます。列車同士は近づきすぎると自動で止まります。
- `RETURN`で急行を出せます（線が空いていて、同時に走れる本数に余裕があるとき）。そのほかは一定時間ごとに普通列車が出ます。
- 8本を届けたとき目標点（24／30／36）以上ならクリア、足りなければ失敗です。44点で銀、60点で金です。ハートを3つ失っても失敗です。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 1つ目の勤務から始める |
| タイトル | `P` | 1つ目の勤務の自動デモ（`DEMO`表示） |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| 勤務 | `W` / `S` | 分岐1／2を選ぶ |
| 勤務 | `D` | 分岐を切り替える |
| 勤務 | `A` | 停止／進行 |
| 勤務 | `RETURN` | 急行を出す |
| 勤務 | `SPACE` | やり直し（確認あり） |
| クリア後 | `RETURN` | 次の勤務 |
| 失敗後 | `RETURN` | やり直し確認 |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 下の`NEXT`に次の3本の行き先が出ます。列車が分岐に着く前に向きを合わせます。
- 急行は点が倍ですが、2本が同じ線にいると手前でつかえます。

## 速さと乱数

上流は10/60秒（約0.17秒）に1 tickです。この版は、固定エミュレータで1 tickが約25万cycle（描画を含む）です。
配達・間違いの演出の間はtickが止まります。
上流の`entropy()`（JR-100のタイマー）は、勤務を始めたときに鳴っていた曲の位置で置き換えています（状態の`origin`、`$4641`）。
自己試験と自動デモでは0に固定します。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$5FFF`（専用stackと自己試験の結果を含む）です。

## 開発と自己試験

tickとキーの時間関係はcycleに依存するため、ルールの一致はプログラム内の自己試験で確かめます
（`sdk/selftest.inc`）。タイトルで`T`を押すと、`tests/selftest.py`の30件のfixture（状態を置いて1 tickまたは1操作）と、
3勤務それぞれの入力スクリプト（tickに同期した操作列）での通し遊びを実行し、結果を`$5000`以降へ書き出します。
`tests/expectations.json`の期待値は`tests/model.py`（上流`rules.py`のPythonモデル）と`tests/selftest_model.py`が計算した値です。
勤務を始める再生では、エミュレータが取った`origin`だけを読み、残りはそのoriginからモデルが計算します。
スクリプトは「分岐に近い列車の行き先へ合わせる」手順と先読みでの急行の判断で作り、3勤務すべてをハートを失わずにクリアします（金・金・銀）。
`P`の自動デモは1つ目の勤務のスクリプトを通常の速さで再生します。
`src/selftest.inc`は`python3 tests/make_selftest.py metro-weave`で生成します。
