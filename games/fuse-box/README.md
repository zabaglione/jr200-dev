# FUSE BOX

5×5のスイッチ盤で、行と列ごとに指定された個数だけヒューズを入れるパズルです。全10面です。
JR100devの`FUSE BOX 1.6.1`（`games/fuse_box/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。面の生成式、行・列の個数の規則、5段階の切り替え演出は上流と同じです。

## 目的と勝敗

- 左の数字は行ごと、上の数字は列ごとに入れるスイッチの個数です。
- すべての行と列の個数が一致すればクリアです。個数が合っていれば、どの配置でも正解です。
- 失敗や回数の上限はありません。やり直すときは`SPACE`で盤を戻します。
- 10面をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `A` / `S` / `D` | スイッチを選ぶ（端では止まる） |
| `RETURN` | 選んだスイッチの入／切を切り替える |
| `SPACE` | この面のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 最初の目標は1面（行2・3・2・2・2、列3・2・2・2・2）をそろえることです。
- 個数の多い行と列が交わるマスから入れると、残りの候補が絞れます。
- 数字が緑の背景に変わった行・列は個数が合っています。入れ過ぎると元の白に戻ります。

## 画面（色と記号）

| もの | 色 | 形 |
| --- | --- | --- |
| 入っているスイッチ | 黄 | 塗りつぶした四角と光る芯 |
| 切れているスイッチ | 青 | 枠だけの四角 |
| 切り替え中 | 白 | 面が細くなり、側面を見せてから反対の面が開く |
| 個数が合った数字 | 緑の背景に黒 | 白黒が反転した数字 |
| 個数が合わない数字 | 黒の背景に白 | 通常の数字 |

右側に面の番号（STAGE）と切り替えた回数（FLIPS）を表示します。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ホ短調の3声の曲（音源F・D・Cを同時に使用、ループ） |
| 切り替え開始・終了 | 短いクリックと2音の効果音（音源C） |
| クリア | 3声のホ長調アルペジオ。直後の効果音の間もF・D声部は鳴り続ける |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
