# ORCHARD DAYS

ベリーとリンゴを植え、水をやり、雨を待って収穫し、28日以内に目標の実り（QUOTA）を集めるゲームです。全3季節です。
JR100devの`ORCHARD DAYS 2.0.0`（`games/orchard_days/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。種と水の数、井戸、雨の周期、ベリーとリンゴの育ち方、収穫、目標は上流と同じです。

## 目的と勝敗

- 16区画の畑と、下段の道具（`BERRY`・`APPLE`・`WAIT`・`WELL`）を選んで`RETURN`で作業します。
- 空き区画には種をまき（種1）、育成中なら水をやり（水1）、実っていれば収穫します（種1が戻る）。
- ベリーは2段育つと実り、収穫で3。リンゴは4段育つと実り、収穫で7です。水をやった区画はその日のうちに1段育ちます。
- `WAIT`は1日待ち、`WELL`は1日使って水を3補給します（水は最大9。満杯のときは日数を使いません）。
  `BERRY`／`APPLE`の選択は日数を使いません。
- 雨は4・5・6日ごと（季節ごと）に降り、育成中の作物がすべて1段育ち、水が4増えます。
- 実りが目標（18、24、30）に届くとクリア、28日を過ぎると失敗（`THE SEASON ENDED BELOW QUOTA`）です。
- 3季節をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `A` / `S` / `D` | 区画や下段の道具を選ぶ |
| `RETURN` | 種まき・水やり・収穫、道具の実行 |
| `SPACE` | この季節のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

種や水滴や実りが飛ぶ演出、雨、作物が1段ずつ育つ演出が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- RAIN INで次の雨までの日数を読みます。雨の直前に種をまいておくと、雨で全部が育ちます。
- ベリーは早く実り、種が戻るので回転が速く、リンゴは1回の収穫が大きくなります。
- 収穫すると種が1戻るので、実った区画にはすぐ植え直せます。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | イ長調の3声の牧歌（音源F・D・Cを同時に使用、ループ） |
| 種まき・水やり・育つ・井戸 | 短い音（音源C） |
| 収穫 | 3音の効果音（音源C） |
| 雨 | 高い粒の音（音源C） |
| 種切れ・水切れ | 低いブザー（音源C） |
| クリア | 3声のイ長調アルペジオ |
| 失敗 | 3声の下がる音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
各季節の作業は、モデル上の貪欲な手順（`best_plan()`）で求めています。リプレイのキー間隔は、モデルが数えた演出のフレーム数から決めています。
