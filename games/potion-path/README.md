# POTION PATH

4種類の材料を注いで薬を盤面上で動かし、毒のマスを避けて注文の位置へ届ける錬金術のパズルです。全20注文です。
JR100devの`POTION PATH 3.0.0`（`games/potion_path/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。注文の位置、毒のマス、最短手数（PAR）、材料ごとの動きと在庫、12回の上限は上流と同じです。

## 目的と勝敗

- 8×8の盤の中央付近から薬が始まります。材料を選んで`RETURN`で注ぐと、薬が材料ごとの向きに動きます。
  - ASH: 左へ2、MOSS: 右へ1・下へ2、SALT: 上へ1、ROOT: 右へ3・下へ1
- 各材料は4回まで使えます。盤の外へ出る注ぎ方、毒のマスへの着地、在庫切れの材料では何も消費しません。毒は飛び越えられます。
- 注文の位置（星）に着くとクリア、12回注いでも届かなければ失敗（`TWELVE DOSES MISSED THE RECIPE`）です。
- 20注文をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。PARは最短の回数です。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `A`、`S` / `D` | 材料を選ぶ（4種類で循環） |
| `RETURN` | 選んだ材料を注ぐ |
| `SPACE` | この注文のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

材料が棚から飛び、薬が次の位置へ移る演出が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- 注文までの横と縦の差を、材料の組み合わせで作ります。上へ動けるのはSALTだけです。
- 毒のマスの位置を先に見て、着地点が毒にならない順番を考えます。
- PARの回数で届く手順が必ずあります。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | イ短調の3声のワルツ（音源F・D・Cを同時に使用、ループ） |
| 注ぐ | 上がる3音（音源C） |
| 薬が動く | 2音（音源C） |
| 在庫切れ・毒への着地 | 低いブザー（音源C） |
| クリア | 3声のイ長調アルペジオ |
| 失敗 | 3声の下がる音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
各注文は幅優先探索（`solve()`）で求めた最短の手順で作ります。その回数は上流のPARと全20注文で一致します。
