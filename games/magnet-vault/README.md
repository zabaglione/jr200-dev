# MAGNET VAULT

磁石で箱を引き寄せ、2つの受け口（菱形）の両方に箱を入れるパズルです。全40の金庫室です。
JR100devの`MAGNET VAULT 1.6.1`（`games/magnet_vault/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。40の金庫室（上流`levels.json`）、歩行と向き、前の箱を引く動き、2つの受け口、任意のルーン、手数とPAR、星の評価は上流と同じです。
ステージマップ、各金庫室の最高評価、パスワードは、上流の評価つきキャンペーンを写したSDKの`sdk/ranked.inc`で動きます（操作はFROST STEPSと共通です）。

## 目的と勝敗

- 上下左右に1マスずつ歩きます。壁と箱は通れません。進めなくても向きは変わります。
- `RETURN`で、向いている前の箱を1マス引き寄せ、自分は1歩後ろへ下がります。後ろが壁や箱なら引けません。押すことはできません。
- 2つの受け口の両方に箱が入るとクリアです。失敗はありません。
- 1歩、向きを変えるだけの操作、1回の引き寄せがそれぞれ1手です。PAR以内なら星2つ、さらにルーンを2つとも通れば星3つ、PARを超えると星1つです。
- 各金庫室の最高評価（BEST）は、やり直し・タイトル・マップへ戻っても残ります。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 選んでいる金庫室を遊ぶ |
| タイトル | `F` | ステージマップ |
| タイトル | `X` | パスワード入力 |
| タイトル | そのほか | 説明 |
| 金庫室 | `W` / `A` / `S` / `D` | 歩く・向きを変える |
| 金庫室 | `RETURN` | 前の箱を引き寄せる |
| 金庫室 | `SPACE` | やり直し（確認あり） |
| 金庫室 | `F` | マップ（確認あり） |
| クリア後 | `RETURN` | 次の金庫室 |
| クリア後 | `SPACE` | やり直し |
| クリア後 | `F` | マップ |
| マップ | `W` / `A` / `S` / `D` | 金庫室を選ぶ |
| マップ | `RETURN` | 遊ぶ |
| マップ | `SPACE` | タイトル |
| マップ | `X` | パスワード |
| パスワード | 英字 | 入力（`ACDEFGHJKMNPQRTW`、大文字・小文字どちらでも） |
| パスワード | `-` / `BACKSPACE` | 1文字消す |
| パスワード | `RETURN` | 読み込む |
| パスワード | `X` | 取り消す |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 箱は引くことしかできないので、箱の向こう側へ回り込んでから受け口の方へ引きます。
- 向きを変えるだけでも1手です。右のFACINGに今の向き（N/S/W/E）が出ます。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`、`tests/ranked_model.py`は上流の評価つきキャンペーンとパスワードを写したPythonモデルです。
`tests/expectations.json`のRAM期待値（盤面、箱、評価、`$4760`の最高評価表）はこれらが計算します。
各金庫室は上流`solutions.json`（星3つ）と`challenges.json`のクリア手順（星2つ）を再生します。40室は1-20、21-30、31-40の3回に分け、2回目以降はパスワードで再開します（1回の実行の上限サイクル数のため）。
