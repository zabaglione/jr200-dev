# PHASE PAIRS

4×4の盤で、上下左右に隣り合い合計が10になる2つの数を組にして消していくパズルです。全10面です。
JR100devの`PHASE PAIRS 1.6.1`（`games/phase_pairs/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。10面の盤（上流`levels.json`）、組の条件、合体の演出、誤りの種類、6回の上限は上流と同じです。

## 目的と勝敗

- 数を選んで`RETURN`で1つ目を決め、隣の数を選んで`RETURN`で2つ目を決めます。
- 2つが上下左右に隣り合い（斜めは不可）、合計が10なら「10」に合体して消えます。16個すべて消すとクリアです。
- 隣でない組は`NEIGHBORS ONLY`、合計が10でない組は`SUM MUST BE 10`で、どちらも誤り（MISS）が1増えます。6回で失敗（`TRY AGAIN - RETURN TO RESTART`）です。
- 10面をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `A` / `S` / `D` | 数を選ぶ |
| `RETURN` | 1つ目・2つ目を決める |
| `SPACE` | この面のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

2枚が寄り合って「10」になり光を散らす演出と、誤りの表示が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- 1つ目を選ぶと、組にできる隣の札の四隅に`*`が付きます。
- 端から消していくと、残った数が隣り合わなくなることがあります。消す順番を先に考えます。
- 札の地の色は、合計10になる組ごとに同じ色です（1と9は赤、2と8は黄、3と7は緑、4と6は水色、5は紫）。

| もの | 色 | 形 |
| --- | --- | --- |
| 数の札 | 組ごとの地の色（上記） | 大きな7セグメントの数字 |
| 1つ目の札 | 札の地に白 | 上辺の`V` |

| 誤り・合体 | 赤・緑 | `NEIGHBORS ONLY`、`SUM MUST BE 10`、`PHASE FUSION!` |

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | 変ロ長調の3声の電子的な曲（音源F・D・Cを同時に使用、ループ） |
| 選ぶ・寄り合う | 短い音（音源C） |
| 合体 | 上がる4音（音源C） |
| 誤り | 低いブザー（音源C） |
| クリア | 3声の変ロ長調アルペジオ |
| 失敗 | 3声の下がる音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
各面は上流`solutions.json`の組の順に解いています。上流の`src/hints.asm`（候補の点滅）は、JR-200版では点灯した`*`に置き換えています。
