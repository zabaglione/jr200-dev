# RIBBON SNAKE

餌を食べて伸びるリボン（蛇）を操り、6つの庭で目標の数だけ餌を食べるアクションゲームです。
JR100devの`RIBBON SNAKE 2.0.0`（`games/ribbon_snake/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。庭ごとの岩の配置、餌の出る場所、目標数（8〜13個）、ブレーキ、
3種類の失敗は上流と同じで、上流の1 tickをこの版の1 tickとして移しています。

## 目的と勝敗

- リボンは一定の間隔で前へ1マス進みます。`W` / `A` / `S` / `D`で向きを変えます。今の向きと正反対の入力は無視されます。
- 餌を食べると1マス伸び、次の餌が出ます。GOALの数だけ食べると庭のクリアです。
- 頭を盤の端・岩・自分の胴体に当てると失敗です（原因が下に出ます）。尻尾は同じ瞬間に動くので、餌を食べない限り尻尾のあったマスへは進めます。
- `RETURN`はブレーキです。8 tickの間、2 tickに1回だけ進みます（4回の移動が半分の速さ）。1つの庭で3回まで使えます。
- 6つ目の庭をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 1つ目の庭から始める |
| タイトル | `P` | 1つ目の庭の自動デモ（`DEMO`表示） |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| 庭 | `W` / `A` / `S` / `D` | 向きを変える |
| 庭 | `RETURN` | ブレーキ |
| 庭 | `SPACE` | やり直し（確認あり） |
| クリア後 | `RETURN` | 次の庭 |
| 失敗後 | `RETURN` | やり直し確認 |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 1つ目の庭は岩が2つ、目標は8個です。餌へまっすぐ向かうより、伸びた胴体の逃げ道を残す向きを選びます。
- 狭い通路はブレーキで速さを落としてから曲がります。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ハ長調の3声のワルツ（音源F・D・Cを同時に使用、ループ） |
| ブレーキ | 下がる3音（音源C） |

| クリア | 3声のハ長調の駆け上がり |
| 失敗 | 3声の下降 |

## 速さ

上流は14/60秒（約0.23秒）に1 tickです。この版は、固定エミュレータで1 tickが約33万cycle（約0.25秒、
描画と滑る演出を含む）です。餌を食べたときの光やぶつかったときの点滅の間はtickが止まります。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$5FFF`（専用stackと自己試験の結果を含む）です。

## 開発と自己試験

tickとキーの時間関係はcycleに依存するため、ルールの一致はプログラム内の自己試験で確かめます
（`sdk/selftest.inc`）。タイトルで`T`を押すと、`tests/selftest.py`の17件のfixture（状態を置いて1 tickまたは1操作）と、
6つの庭それぞれの入力スクリプト（tickに同期した操作列）での通し遊びを実行し、結果を`$5000`以降へ書き出します。
`tests/expectations.json`の期待値は`tests/model.py`（上流`rules.py`のPythonモデル）と`tests/selftest_model.py`が計算した値です。
スクリプトはモデル上の探索で作り、6つの庭すべてをクリアします。`P`の自動デモは1つ目の庭のスクリプトを通常の速さで再生します。
`src/selftest.inc`は`python3 tests/make_selftest.py ribbon-snake`で生成します。
