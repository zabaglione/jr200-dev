# PRISM TRACE

7×7の盤にある6枚の鏡の向きを変え、左から入る光を右上の受光器へ届けるパズルです。1面です。
JR100devの`PRISM TRACE 1.6.1`（`games/prism_trace/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。鏡の配置、光の進み方と反射、同じ入り方を2度たどったら止まる規則、受光器は上流と同じです。
光の線は上流の`src/optics.asm`（JR-100の文字の組み合わせ）ではなく、JR-200の色付きタイルで描きます。

## 目的と勝敗

- 鏡のあるマスを選んで`RETURN`を押すと、`/`と`\`が入れ替わります。光の道はすぐに引き直されます。
- 光が右上の受光器に届くとクリアです。失敗はありません。
- クリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。ROTATIONSは鏡を回した回数です。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `A` / `S` / `D` | マスを選ぶ（上の`V`と右の`<`の交点） |
| `RETURN` | 選んだマスの鏡を回す（鏡のないマスでは何もしない） |
| `SPACE` | 鏡を元に戻す確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

光が1マスずつ伸び、鏡で反射音とともに折れる演出が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- 光は左の`IN`から右へ進みます。まず光が当たっている鏡から、進みたい向きへ回します。
- 同じ場所を同じ向きで2度通ると光は止まります（ループしません）。
- 5枚の鏡を回すと届きます。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ホ長調の3声のきらめく分散和音（音源F・D・Cを同時に使用、ループ） |
| 鏡を回す | 2音（音源C） |
| 鏡での反射 | 短い高い音（音源C） |
| クリア | 3声のホ長調アルペジオ |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
回す鏡は、受光器に届く最小の組（`plan()`）です。より小さい組では届かないので、途中で先にクリアすることはありません。
