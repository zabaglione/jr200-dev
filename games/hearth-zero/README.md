# HEARTH ZERO

最後の炉を守り、薪・食料・暖かさをやりくりして寒波の12夜を生き延びる経営・サバイバルゲームです。
寒波は3種類あり、それぞれ12日間です。JR100devの`HEARTH ZERO 2.1.0`（`games/hearth_zero/rules.py`）を
仕様として、JR-200向けにM6800アセンブリで作り直しました。資源の増減・上限、断熱、天候表、
1日の処理順、2種類の敗北は上流と同じです。

## 目的と勝敗

- 毎日1つ仕事を選びます。夜には食料を2つ食べ、その夜の寒さ（から断熱を引いた値）だけ暖かさが減ります。
- 12夜を越えると寒波をしのぎ、次の寒波へ進みます。3つの寒波を越えるとクリアです。
- 夜に食料が2つ未満なら`NO FOOD LEFT FOR THE NIGHT`、暖かさが寒さ以下なら
  `THE NIGHT EXTINGUISHED THE HEARTH`で失敗します（食料の判定が先）。

| 仕事 | 効果 |
| --- | --- |
| `WOOD` | 薪+7（上限30） |
| `FOOD` | 食料+7（上限30） |
| `FIRE` | 薪3を使い暖かさ+9（上限24）。薪が3未満だと`FIRE NEEDS THREE WOOD` |
| `WALL` | 薪4を使い断熱+1（最大2）。毎晩の寒さが1減る。条件外は`WALL: FOUR WOOD, MAX TWO` |

## 操作

| key | 動作 |
| --- | --- |
| `A` / `D`（`W` / `S`も可） | 仕事を選ぶ（左右で循環） |
| `RETURN` | 選んだ仕事で1日を進める。タイトルでは開始、寒波を越えた後は次の寒波 |
| `SPACE` | やり直し確認（初期選択NO） |
| `CTRL+C` | ゲームの終了処理を通してBASICへ戻る。Webエミュレータでは`CTRL+SHIFT+C`で送る |

1日の演出（仕事の品が炉へ飛ぶ、炎と雪、食事、冷え込み）の間に押したキーは捨てられます。
ジョイスティックには対応していません。
Webエミュレータの`Escape`キーはJR-200の`BREAK`（NMI）です。ゲームの終了処理を通らず、
画面が復元されないため、終了操作には使わないでください。

## 最初の目標と序盤のコツ

- `COLD NOW/NEXT`は今夜と次の2夜、合わせて3夜の寒さの予報です（ゲームの長さは12日）。
- 最初の目標は最初の寒波の12夜を越えることです。薪が8あるうちに壁を2つ作ると、以後の毎晩の
  寒さが2ずつ軽くなります。
- 暖かさの残りが次の夜の寒さを下回りそうなら、その日のうちに`FIRE`で備えます。食料は
  1日2ずつ減るので、5日に1回ほどの`FOOD`で足ります。

## 画面

左上の炉と下の炎の列が暖かさ（2につき1つ）、右に食料・薪・暖かさ・断熱の数値、予報、日数を
表示します。仕事の名前は下の行、選択中の仕事の下に`>`が付きます。資源は色（食料は緑、薪は赤、
暖かさは黄、断熱は白）と名前の両方で示します。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAMは起動前の状態に戻ります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`（専用stackを含む）です。

## 開発

`tests/expectations.json`のRAM期待値は`tests/model.py`が計算した値です。`synthetic-all-waves`は
3つの寒波を12夜ずつ越え、`synthetic-lose-heat`と`synthetic-lose-food`は2種類の敗北を再現します。
