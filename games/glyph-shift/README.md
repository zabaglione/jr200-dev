# GLYPH SHIFT

「箱が壁」と「敵が壁」の規則を書き換えながら通り道を作り、菱形の門へたどり着くパズルです。全40部屋です。
JR100devの`GLYPH SHIFT 1.6.1`（`games/glyph_shift/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。40部屋（上流`levels.json`）、規則の書き換え、門、任意のルーン、手数とPAR、星の評価は上流と同じです。
ステージマップ、各部屋の最高評価、パスワードは、上流の評価つきキャンペーンを写したSDKの`sdk/ranked.inc`で動きます（操作はFROST STEPSと共通です）。

## 目的と勝敗

- 上下左右に1マスずつ歩きます。壁は通れません。
- `RETURN`で規則を書き換えます。初めは箱が壁で敵は通れ、書き換えると敵が壁で箱は通れます。
- 門（菱形）に着くとクリアです。失敗はありません。
- 1歩と1回の書き換えがそれぞれ1手です。PAR以内なら星2つ、さらにルーンを2つとも通れば星3つ、PARを超えると星1つです。
- 各部屋の最高評価（BEST）は、やり直し・タイトル・マップへ戻っても残ります。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 選んでいる部屋を遊ぶ |
| タイトル | `F` | ステージマップ |
| タイトル | `X` | パスワード入力 |
| タイトル | そのほか | 説明 |
| 部屋 | `W` / `A` / `S` / `D` | 歩く |
| 部屋 | `RETURN` | 規則を書き換える |
| 部屋 | `SPACE` | やり直し（確認あり） |
| 部屋 | `F` | マップ（確認あり） |
| クリア後 | `RETURN` | 次の部屋 |
| クリア後 | `SPACE` | やり直し |
| クリア後 | `F` | マップ |
| マップ | `W` / `A` / `S` / `D` | 部屋を選ぶ |
| マップ | `RETURN` | 遊ぶ |
| マップ | `SPACE` | タイトル |
| マップ | `X` | パスワード |
| パスワード | 英字 | 入力（`ACDEFGHJKMNPQRTW`、大文字・小文字どちらでも） |
| パスワード | `-` / `BACKSPACE` | 1文字消す |
| パスワード | `RETURN` | 読み込む |
| パスワード | `X` | 取り消す |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 書き換えも1手です。書き換える回数が少ない道を探します。
- 右のRULE TABLEで、いま壁になっている方が赤い地で表示されます。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ニ短調の3声の行進曲（音源F・D・Cを同時に使用、ループ） |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`、`tests/ranked_model.py`は上流の評価つきキャンペーンとパスワードを写したPythonモデルです。
`tests/expectations.json`のRAM期待値（盤面、評価、`$4760`の最高評価表）はこれらが計算します。
各部屋は上流`solutions.json`（星3つ）と`challenges.json`のクリア手順（星2つ）を再生します。40部屋は20部屋ずつに分け、後半はパスワードで21部屋目から再開します。
