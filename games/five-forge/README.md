# FIVE FORGE

8×8の盤で、縦・横・斜めのどれかに自分の石を5つ並べる五目並べです。1面です。
JR100devの`FIVE FORGE 1.6.1`（`games/five_forge/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。五連の判定、相手の手の選び方（攻め×3＋守り、すぐの五連を最優先で防ぐ）、
石の落下と五連の点滅は上流と同じです。

## 目的と勝敗

- 空いたマスを選んで石を置くと、相手がすぐに1手打ち返します。
- 先に5つ並べるとクリア、相手が5つ並べると失敗（`RIVAL COMPLETED FIVE`）です。
- 盤が埋まっても五連ができなければ失敗（`BOARD FULL - NO FIVE`）です。
- 1面をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

相手は、空きマスごとに「そこに置いたときの自分の最長の並び×3＋あなたの最長の並び」を計算し、最も高いマスに打ちます。
相手が5つ並べられるマスが最優先、次にあなたの五連を防ぐマスです。同点なら左上に近いマスを選びます。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `A` / `S` / `D` | マスを選ぶ |
| `RETURN` | 石を置く（石のあるマスでは何もしない） |
| `SPACE` | やり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

石が落ちてつぶれ、元の形に戻る演出と、相手の考慮と着手が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- 相手はすぐの五連しか確実には防ぎません。両端が空いた4つの並びを作ると勝てます。
- 相手の石の並びも見て、相手の4つの並びは早めに止めます。

## 画面（色と記号）

| もの | 色 | 形 |
| --- | --- | --- |
| 盤 | 黄の地に黒 | 十字の目 |
| 自分の石 | 黄の地に白 | 白い石 |
| 相手の石 | 黄の地に黒 | 黒い石 |
| カーソル | 黄の地に赤 | 角の印。石の上では水色の地 |
| 置いている石 | 水色の地 | 上から落ち、つぶれて戻る |
| できた五連 | 紫の地 | 3回点滅してから残る |
| 手番 | 白（あなたの番）、黄（あなたの着手）、赤（相手の着手）、緑（最後の手） | 文字 |

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | 変ロ長調の3声の行進曲（音源F・D・Cを同時に使用、ループ） |
| 石を置く | 落ちる2音と着地の音（音源C） |
| 五連の点滅 | 短い音（音源C） |
| クリア | 3声の変ロ長調アルペジオ |
| 失敗 | 3声の下がる音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
勝つ手順は、モデル上の相手に対する深さ優先探索（`plan()`）で求めた5手です。
