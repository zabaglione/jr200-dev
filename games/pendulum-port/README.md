# PENDULUM PORT

振り子のロープにつかまって揺れ、手を離して港の足場へ飛び移るアクションゲームです。全6航路です。
JR100devの`PENDULUM PORT 2.0.0`（`games/pendulum_port/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。揺れ方（1 tickに1段、0〜15で折り返し）、3段階のロープの長さ、
着地点の予測、足場の位置と幅、得点、残りロープ（ライフ）は上流と同じで、上流の1 tickをこの版の1 tickとして移しています。

## 目的と勝敗

- 振り子は左右に揺れ続けます。`RETURN`で手を離すと、揺れの勢いのまま飛び、下の`V`印の位置に着地します。
- `A`でロープを短く、`D`で長くします（1〜3）。長いほど遠くへ飛びます。
- 足場（黄）に着地すれば1点、中央（緑）なら2点で、次の足場が出ます。6回＋（航路番号−1）回着地すると航路のクリアです。
- 足場を外すと海に落ちてロープを1本失います。3本とも失うと失敗です。
- 後半の航路（4つ目から）では3回に1回、中央だけの狭い足場になります。
- 6つ目の航路をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 1つ目の航路から始める |
| タイトル | `P` | 1つ目の航路の自動デモ（`DEMO`表示） |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| 航路 | `A` / `D` | ロープを短く／長く |
| 航路 | `RETURN` | 手を離して飛ぶ |
| 航路 | `SPACE` | やり直し（確認あり） |
| クリア後 | `RETURN` | 次の航路 |
| 失敗後 | `RETURN` | やり直し確認 |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- `V`印が足場の中央に重なった瞬間に`RETURN`を押します。
- 揺れの向き（上の`>`／`<`）で着地点が変わります。戻り側では印が振り子の手前に出ます。

## 速さ

上流は6/60秒（0.1秒）に1 tickです。この版は、固定エミュレータで1 tickが約15万cycle（約0.11秒、描画を含む）です。
飛んでいる間と着地の演出の間はtickが止まります。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$5FFF`（専用stackと自己試験の結果を含む）です。

## 開発と自己試験

tickとキーの時間関係はcycleに依存するため、ルールの一致はプログラム内の自己試験で確かめます
（`sdk/selftest.inc`）。タイトルで`T`を押すと、`tests/selftest.py`の19件のfixture（状態を置いて1 tickまたは1操作）と、
6つの航路それぞれの入力スクリプト（tickに同期した操作列）での通し遊びを実行し、結果を`$5000`以降へ書き出します。
`tests/expectations.json`の期待値は`tests/model.py`（上流`rules.py`のPythonモデル）と`tests/selftest_model.py`が計算した値です。
スクリプトはモデル上の探索（予測位置が中央に重なったら離す）で作り、6つの航路すべてをクリアします。
`P`の自動デモは1つ目の航路のスクリプトを通常の速さで再生します。
`src/selftest.inc`は`python3 tests/make_selftest.py pendulum-port`で生成します。
