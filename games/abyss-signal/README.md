# ABYSS SIGNAL

32×32マスの暗い海で小さな潜水艇を操り、5つの観測地点を記録して基地へ帰還する海底探索ゲームです。
JR100devの`ABYSS SIGNAL 1.6.1`（`games/abyss_signal`）を仕様として、JR-200向けにM6800アセンブリで作り直しました。
上流はJR-100向けの手書きアセンブリで、ルールは上流の`model.py`（Pythonの独立モデル）と一致します。この版の`tests/model.py`は
その`advance()`をそのまま持ち、上流`src/main.asm`の操作パネル・観測画面・確認を加えた検証用モデルです。
海域の地図と5地点は上流の`world.json`です。

## 目的と勝敗

- `W`/`A`/`S`/`D`で1マス進みます。移動と待機（`X`）は酸素1（静音中は2）を使います。岩礁にぶつかると船体が1損傷します。
- 海流（E/S/W/Nの文字）に入ると、その向きへ1マス押され、酸素をさらに1使います。
- 普段の視界は距離2です。`F`のソナーは酸素2を使い、6行動の間、視界を距離6に広げます。ソナーの音は追跡者を引き寄せます。
- 追跡者（赤）は通常2行動ごと、静音中は4行動ごとに動き、距離6以内かソナーの音があると追ってきます。距離1以内で接触すると船体が1損傷し、その後4行動は猶予があります。
- 未記録の地点の上か上下左右の隣で、パネルの`RECORD SITE`を選ぶと記録します（酸素2）。記録ごとに遺構の観測画面が開きます。
- 5地点をすべて記録して出発地点（基地）へ戻ると成功です。酸素か船体が0になると失敗（`CONNECTION LOST`）です。
- パネル操作、観測画面、何も入力していない間は、時間も酸素も進みません。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 潜航を始める |
| タイトル | そのほか | 説明 |
| 海 | `W` / `A` / `S` / `D` | 1マス進む |
| 海 | `F` / `X` | ソナー／待機 |
| 海 | `RETURN` / `SPACE` | 操作パネル |
| パネル | `W` / `S` | 選ぶ（端で反対側へ回る） |
| パネル | `RETURN` | SONAR PING／RECORD SITE／QUIET MODE／WAIT／RESTART／TITLE |
| パネル | `SPACE` | 閉じる |
| RESTART？／TITLE？ | `A` / `D` | YES／NO（最初はNO） |
| RESTART？／TITLE？ | `RETURN` / `SPACE` | 決定／取り消し（パネルへ戻る） |
| 観測画面 | `RETURN` / `SPACE` | 海へ戻る |
| 成功後 | `RETURN` | 結果画面、もう一度でタイトル |
| 失敗後 | `RETURN` | やり直すか確認（`D`でYES） |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 右の計器の`RANGE`と`BEARING`は、次の未記録地点（全記録後は基地）までの距離と方位、左下の`TO:`はその名前です。
- 酸素30以下では`!!!`が赤く点き、4行動ごとに警報が鳴ります。追跡者が距離6以内のときも`CONTACT`と警報で知らせます。
- 静音（QUIET MODE）は酸素を倍使う代わりに、追跡者の動きを半分にします。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ニ短調の3声のゆっくりした下降（音源F・D・Cを同時に使用、ループ） |
| 移動・パネル | 短い音（音源C） |
| 衝突・被弾 | 低い3音（音源C） |
| ソナー | 間をおいた2音（音源C） |
| 海流 | 2音（音源C） |
| 記録 | 上がる4音（音源C） |
| 記録できない | 低い1音（音源C） |
| 警報 | 2回の短い音（音源C） |
| 成功 | 3声のニ長調の上昇 |
| 失敗 | 3声の下降 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`（専用stackを含む）です。
海域の地図は1マス4bitで収め（`src/world.inc`）、行の番地表で引きます。

## 開発と検証

ターン制なので、タイトル・パネル・各規則・通しの成功と失敗を固定エミュレータのキーreplayで確かめます。
`tests/expectations.json`の期待値は`tests/model.py`が計算した値で、エミュレータの出力を写したものではありません。
`synthetic-survey`は上流`replay.py`と同じ手順（各区間でソナー、最短経路、パネルから記録、最後に基地）で117行動を再生し、
酸素80・船体4を残して成功します（上流の試験と同じ結果）。キーの間隔は1行動30万cycle、ソナーは130万cycleです。
ソナーの走査線は、描画全体をやり直さず線だけを画面へ書くため、1段ごとに1フレームです。
`src/world.inc`は`python3 games/abyss-signal/tests/make_world.py`で生成します。
