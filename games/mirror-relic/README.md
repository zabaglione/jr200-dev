# MIRROR RELIC

縦横の壁で4つに区切られた広間を歩き、鏡の回転で位置を移しながら、3つの遺物を
合った位相（A〜D）で拾って出口へ向かう探索パズルです。全6広間です。JR100devの
`MIRROR RELIC 3.0.0`（`games/mirror_relic/rules.py`）を仕様として、JR-200向けにM6800アセンブリで
作り直しました。広間の形、通路、遺物の位置と位相、回転の規則、20回の上限は上流と同じです。

## 目的と勝敗

- 遺物は、今の位相（PHASE）が遺物の文字と同じときに、その上に立つと拾えます。
- 3つ拾うと出口が開き（`EXIT OPEN`）、出口に立つとクリアです。
- 回転は時計回りと反時計回りの2種類で、広間の中の位置を90度回した場所へ移ります。
  時計回りで位相が1つ進み（A→B→C→D→A）、反時計回りで1つ戻ります。壁の位置へは回転できません。
- 回転を20回使うと失敗（`TWENTY ROTATIONS BEFORE EXIT`）です。
- 6広間をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `A` / `S` / `D` | 1マス歩く（壁では向きだけ変わる） |
| `RETURN` | 時計回りに回転する（移り先に`>`が出る） |
| `X` | 反時計回りに回転する |
| `SPACE` | この広間のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

回転の移動と遺物の光の演出が終わってから次のキーを押してください。演出中のキーは捨てられます。

## 最初の目標と序盤のコツ

- 1広間の遺物はBが1つ、Cが1つ、Dが1つです。最初の位相はAなので、まず回転で位相を合わせます。
- 時計回りの移り先は`>`で予告されます。回転は位置と位相を同時に変えるので、両方を先に考えます。
- 位相だけを変えたいときは、時計回りと反時計回りを組み合わせると元の場所へ戻れます（位相も戻ります）。

## 画面（色と記号）

| もの | 色 | 形 |
| --- | --- | --- |
| 壁 | 青の地に白 | 陰影のある四角 |
| 床 | 青 | 点 |
| 遺物（位相A/B/C/D） | 赤／紫／緑／水色 | ひし形と左上の文字 |
| 出口 | 緑、開くと黄 | 扉 |

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ニ短調の3声の曲（音源F・D・Cを同時に使用、ループ） |
| 歩く | 短いクリック（音源C） |
| 回転 | 下がっていく4音（音源C） |
| 遺物を拾う | 3音の効果音（音源C） |
| クリア | 3声のニ長調アルペジオ |
| 回転切れ | 3声の下がるニ短調の音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
各広間の解答はモデルの幅優先探索（最少の操作数）で求めています。`X`キーは`sdk/keys_ext.inc`の
作品別キー表で上流の操作7（反時計回り）に割り当てています。
