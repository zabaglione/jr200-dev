# LUNAR TOUCHDOWN

噴射と左右の操作で着陸船を降ろし、速さ2以下で着陸台に降り立つアクションゲームです。全6か所の着陸地です。
JR100devの`LUNAR TOUCHDOWN 2.0.0`（`games/lunar_touchdown/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。重力（3 tickごとに落下速度+1、最大5）、噴射と燃料、2か所目からの横風、
広い台と`*`の狭い台、着陸速度の条件、得点は上流と同じで、上流の1 tickをこの版の1 tickとして移しています。

## 目的と勝敗

- 着陸船は落ち続けます。`W`または`RETURN`で噴射すると落下速度（FALL）が2下がり、燃料（FUEL）を1使います。
- `A` / `D`で左右に1マス動きます。
- 高度（ALT）が0になったとき、広い台（緑）か狭い台（黄、下に`*`）の上にいて、FALLが2以下なら着陸成功です。
- FALLが3以上なら`DESCENT SPEED TOO HIGH`、台の外なら`MISSED BOTH LANDING PADS`で失敗です。
- 2か所目からは4 tickごとに横風で1マス流されます。風向き（WIND の`>` / `<`）は16 tick（4か所目からは12 tick）ごとに変わります。
- 得点は残り燃料、狭い台なら+10、FALLが1以下なら+4です。
- 6か所目に着陸すると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 1か所目から始める |
| タイトル | `P` | 1か所目の自動デモ（`DEMO`表示） |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| 着陸地 | `W` / `RETURN` | 噴射 |
| 着陸地 | `A` / `D` | 左右へ動く |
| 着陸地 | `SPACE` | やり直し（確認あり） |
| クリア後 | `RETURN` | 次の着陸地 |
| 失敗後 | `RETURN` | やり直し確認 |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 先に台の上へ動いておき、高度が下がってからFALLを2以下へ落とします。
- 噴射の直後は炎が出ます。燃料を残すほど得点が上がります。

## 速さ

上流は15/60秒（0.25秒）に1 tickです。この版は、固定エミュレータで1 tickが約30万cycle（約0.22秒、描画と降下の演出を含む）です。
噴射と着陸・衝突の演出の間はtickが止まります。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$5FFF`（専用stackと自己試験の結果を含む）です。

## 開発と自己試験

tickとキーの時間関係はcycleに依存するため、ルールの一致はプログラム内の自己試験で確かめます
（`sdk/selftest.inc`）。タイトルで`T`を押すと、`tests/selftest.py`の23件のfixture（状態を置いて1 tickまたは1操作）と、
6か所それぞれの入力スクリプト（tickに同期した操作列）での通し遊びを実行し、結果を`$5000`以降へ書き出します。
`tests/expectations.json`の期待値は`tests/model.py`（上流`rules.py`のPythonモデル）と`tests/selftest_model.py`が計算した値です。
スクリプトはモデル上の深さ優先探索で作り、6か所すべてに着陸します（2か所目と4か所目は狭い台）。
`P`の自動デモは1か所目のスクリプトを通常の速さで再生します。
`src/selftest.inc`は`python3 tests/make_selftest.py lunar-touchdown`で生成します。
