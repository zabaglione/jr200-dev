# CIRCUIT WORKS

3段につないだ論理ゲートの種類を変えて、3入力の全8通りで目標の出力Wと一致させる全22問の
パズルです。JR100devの`CIRCUIT WORKS 2.1.0`（`games/circuit_works/rules.py`）を仕様として、
JR-200向けにM6800アセンブリで作り直しました。ゲートの計算、22問の目標、試験の手順、TESTSの
回数は上流と同じです。

## 目的と勝敗

- 回路は`G1 = A op B`、`G2 = G1 op C`、`G3 = G2 op A`です。opはAND／OR／XORのどれかです。
- 右の表の`W`は目標の出力、`NOW`は試験した出力です。`RETURN`で全8行を試験し、8行すべてが
  一致（`MATCHED 08/8`）すれば次の問題へ進めます。失敗や回数の上限はありません。
- 22問を解くと`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `S` | ゲートG1〜G3を選ぶ（上下で循環） |
| `A` / `D` | 選んだゲートの種類を AND → OR → XOR の順に切り替える（循環） |
| `RETURN` | 全8入力を試験。タイトルでは開始、正解後は次の問題 |
| `SPACE` | やり直し確認（初期選択NO） |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

試験中は、処理中のゲートに`*`、流れる0/1が配線上に表示され、表の`>`が試験中の行を示します。
一致した行は緑の`*`、違う行は赤の`X`です。値は0が水色、1が黄色で、色と文字の両方で読めます。
演出中に押したキーは捨てられます。ジョイスティックには対応していません。

## 最初の目標と序盤のコツ

- 第1問は全ゲートがAND（初期状態）で正解です。まず`RETURN`で試験の流れを見てください。
- 表の読み方: 各行は左からA、B、Cの入力と、目標W、今の出力NOWです。
- `W`が1になる行と0になる行を比べ、最後のG3（相手はA）から逆にたどると考えやすくなります。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAMは起動前の状態に戻ります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`（専用stackを含む）です。

## 開発

`tests/expectations.json`のRAM期待値は`tests/model.py`が計算した値です。`synthetic-all-stages`は
22問すべての正解の組合せを入力して試験します。`tests/test_circuit_works.py`は27通りのゲートの
組合せ×8入力を別の論理式で照合し、全問に解があることを確認します。
