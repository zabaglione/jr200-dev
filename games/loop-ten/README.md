# LOOP TEN

10秒ごとに最初の部屋の出発点へ戻される時間ループから、12の部屋の封印をすべて点灯させて脱出する探索パズルです。
JR100devの`LOOP TEN 1.6.1`（`games/loop_ten`）を仕様として、JR-200向けにM6800アセンブリで作り直しました。
上流はJR-100向けの手書きアセンブリで、Pythonのルールモデルがありません。この版の`tests/model.py`は
上流のアセンブリ（`REWIND`、`GAME_INPUT`、`MOVE_TEST`、`GATE`、`HAZARD`、`INTERACT`、`TIMER_TICK`と押し続けの反復）と
`check_rules.py`／`replay.py`から作った検証用モデルです。12部屋の地図と名前は上流の`rooms.json`です。

## 目的と勝敗

- 部屋は16×10マスです。`W`/`A`/`S`/`D`で歩きます。押し続けると繰り返し歩きます。
- 菱形の封印の上か上下左右の隣で`RETURN`を押すと封印が点灯し、その部屋の右端の扉が開きます。扉を通ると次の部屋です。
- 10秒たつと、最初の部屋の出発点へ戻されます（ループ）。点灯した封印と開いた扉は、巻き戻っても残ります。
- 各部屋の出発点にある時計（アンカー）の上で`RETURN`を押すと、最初の未点灯の部屋へ移ります。
- 点灯済みの封印をもう一度使うか`SPACE`で、早めに巻き戻せます。赤い床（罠）に触れても巻き戻ります。
- 12番目の部屋の封印を点灯させると脱出です（ループ数を表示）。失敗はありません。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 始める |
| タイトル | `P` | 自動デモ（脱出まで、`DEMO`表示） |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| 探索 | `W` / `A` / `S` / `D` | 歩く（押し続けで繰り返し） |
| 探索 | `RETURN` | 封印を使う／アンカーで移動する |
| 探索 | `SPACE` | 早めに巻き戻す |
| 脱出後 | `RETURN` | 結果画面、もう一度でタイトル |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- 最初のループで1部屋目の封印を点灯させます。2回目のループからは、出発点のアンカーで次の部屋へ直行できます。
- 上段の`TIME`は残り秒数、`LOOP`はループ回数、`ROOM`は部屋番号です。2段目は残り時間のバー（最後の3秒は赤、秒ごとに音）と、12個の封印の点灯状態です。

## 速さ

上流は1秒60 tickで、10秒は600 tick、押し続けは6 tickごとに繰り返します。この版の1 tickは上流の6 tick（0.1秒）で、
1ループは100 tickです。固定エミュレータでは1 tickが約14.5万cycle（描画を含み約0.108秒）なので、1ループは約10.8秒です。
上流と同じく、封印・罠・巻き戻しの演出の間は時計が止まります（上流`FX_BEGIN`）。
押し続けの最初の繰り返しは、押してから1〜2 tick後です（キーを押した時刻はtickの間にあるため）。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$5FFF`（専用stackと自己試験の結果を含む）です。
押し続けはキーボードMCUの走査（`sdk/keyscan.inc`）で読みます。

## 開発と自己試験

tickとキーの時間関係はcycleに依存するため、ルールの一致はプログラム内の自己試験で確かめます
（`sdk/selftest.inc`）。タイトルで`T`を押すと、`tests/selftest.py`の18件のfixture（歩行、壁、閉じた扉と開いた扉、罠、
アンカー、封印の点灯と再使用、最後の封印、手動の巻き戻し、時計、時間切れ、押し続けの反復）と、
上流`replay.py`と同じ最短経路で12部屋を順に点灯させる入力スクリプトを実行し、結果を`$5000`以降へ書き出します。
`tests/expectations.json`の期待値は`tests/model.py`と`tests/selftest_model.py`が計算した値で、エミュレータの出力を写したものではありません。
`P`の自動デモは同じスクリプトを通常の速さで再生します（12ループで脱出）。
`src/rooms.inc`は`python3 games/loop-ten/tests/make_rooms.py`、`src/selftest.inc`は`python3 tests/make_selftest.py loop-ten`で生成します。
