# GATE RUNNER

奥から迫る門（壁・穴・低い梁）を左右の移動とジャンプでかわし、結晶を拾いながら走り抜けるアクションゲームです。全6コースです。
JR100devの`GATE RUNNER 3.0.0`（`games/gate_runner/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。門の種類と位置・結晶の表（上流`game.json`の`dataTables`）、偶数コースの左右反転、
1歩移動と押し続けの走り、ジャンプの高さの変化、当たり判定、3回の被弾、金・銀・銅の結果は上流と同じで、
上流の1 tickをこの版の1 tickとして移しています。道路の遠近の描き方はこの版独自です（上流の`widths`／`floors`表を使います）。

## 目的と勝敗

- 門は道路の奥から近づき、20 tickに1つ走者の位置に来ます。そのとき走者の位置と高さで判定します。
- `A` / `D`を押すと1歩、押し続けると毎tick 1歩ずつ走ります（列2〜28）。`W`または`RETURN`でジャンプします（着地するまで次は跳べません）。
- 壁（赤）はよけます。穴（青）は跳び越えます（道幅いっぱいの穴もあります）。低い梁（紫）は地面にいればくぐれ、跳ぶと当たります。
- 当たると船体（HULL）の`*`を1つ失い、3つ失うと失敗です。
- 結晶（水色）は門の危ない側や空中にあります。1列以内で、地上か空中かが合えば取れます。
- コース1は9門、以降は12門を越えるとクリアです。取り逃しが2つ以下なら`GOLD RUN`、半分以上なら`SILVER RUN`、それ以外は`BRONZE RUN`です。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 1つ目のコースから始める |
| タイトル | `P` | 1つ目のコースの自動デモ（`DEMO`表示） |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| コース | `A` / `D` | 1歩（押し続けで走る） |
| コース | `W` / `RETURN` | ジャンプ |
| コース | `SPACE` | やり直し（確認あり） |
| クリア後 | `RETURN` | 次のコース |
| 失敗後 | `RETURN` | やり直し確認 |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

押し続けの判定はキーボードMCUの走査（BRICK PULSEと同じ`sdk/keyscan.inc`）で読みます。キーを離すと次のtickで止まります。

## 最初の目標と序盤のコツ

- 門が画面の下に来る少し前に位置を決めます。ジャンプは門の2〜5 tick前に押すと、門の位置で空中にいます。
- 奥にある次の門を見て、先に動いておきます。

## 速さ

上流は6/60秒（0.1秒）に1 tickです。この版は、固定エミュレータで1 tickが約17万cycle（約0.125秒、描画とキー走査を含む）です。
被弾と結晶の演出の間はtickが止まります。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$5FFF`（専用stackと自己試験の結果を含む）です。
ROMなしの固定エミュレータでは、キー走査の初期化（MCUのフォント転送の読み捨て）に約130万cycleかかるため、試験の操作はその後に始めます。

## 開発と自己試験

tickとキーの時間関係はcycleに依存するため、ルールの一致はプログラム内の自己試験で確かめます
（`sdk/selftest.inc`）。タイトルで`T`を押すと、`tests/selftest.py`の26件のfixture（状態を置いて1 tickまたは1操作）と、
6コースそれぞれの入力スクリプト（tickに同期した操作列。押し続けの向きも含む）での通し遊びを実行し、結果を`$5000`以降へ書き出します。
`tests/expectations.json`の期待値は`tests/model.py`（上流`rules.py`のPythonモデル）と`tests/selftest_model.py`が計算した値です。
スクリプトはモデル上で門ごとの深さ優先探索で作り、6コースすべてを被弾なし・結晶をすべて取ってクリアします。
`P`の自動デモは1つ目のコースのスクリプトを通常の速さで再生します。
`src/selftest.inc`は`python3 tests/make_selftest.py gate-runner`で生成します。
