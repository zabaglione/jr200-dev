# SHADOW ARCHIVE

6人の容疑者から、帽子・眼鏡・ネクタイの調書を読んで犯人を1人だけ見つける推理ゲームです。全12件です。
JR100devの`SHADOW ARCHIVE 2.1.0`（`games/shadow_archive/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。12件の容疑者と犯人、調書と告発の規則は上流と同じです。

## 目的と勝敗

- 調書は3冊（1 帽子、2 眼鏡、3 ネクタイ）で、開くと犯人がその特徴を持つか（YES/NO）が分かります。
- 開いた調書と食い違う容疑者は赤くなり、`X`が付きます。
- 犯人を告発するとクリア、別の人を告発すると失敗（`THE SUSPECT DOES NOT FIT`）です。
- 調書2冊以内で解くと`GOLD DETECTIVE`、3冊なら`CASE CLOSED`と表示します。
- 12件をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| key | 動作 |
| --- | --- |
| `W` / `S` | 調書を開くモードと告発のモードを切り替える |
| `A` / `D` | 調書または容疑者を選ぶ（循環）。2つのモードの選択位置は別々に残る |
| `RETURN` | 調書を開く、または選んだ容疑者を告発する |
| `SPACE` | この件のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

## 最初の目標と序盤のコツ

- どの件も、調書2冊で犯人が1人に絞れます（GOLD）。
- 容疑者の下の3文字は、帽子・眼鏡・ネクタイの順にY（あり）とN（なし）です。
  残る容疑者を最も分ける調書から開きます。

## 画面（色と記号）

| もの | 色 | 形 |
| --- | --- | --- |
| 容疑者 | 白 | 顔の絵。帽子・眼鏡・ネクタイが絵にも描かれる |
| 食い違う容疑者 | 赤 | 名前の横に`X` |
| 特徴あり／なし | 緑のY／赤のN | 顔の下の3文字 |
| 調書の答え | 緑のYES／赤のNO | 右の調書の欄 |
| 選択 | 黄 | `>` |
| 告発した相手 | 赤 | 顔の右に`!` |

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ロ短調の3声の曲（音源F・D・Cを同時に使用、ループ） |
| 調書をめくる・告発 | 短いクリック（音源C） |
| 調書を読み終える | 2音の効果音（音源C） |
| 解決 | 3声のロ長調アルペジオ |
| 誤認 | 3声の下がるロ短調の音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
失敗の表示は、画面の状態行に収まるように上流より短くしています。
