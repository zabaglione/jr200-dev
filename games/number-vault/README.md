# NUMBER VAULT

4つのダイヤル（数字1〜4）の暗証番号を、EXACTとNEARの手がかりから10回以内に当てて
金庫を開けるパズルです。全10面です。JR100devの`NUMBER VAULT 2.1.0`（`games/number_vault/rules.py`）を
仕様として、JR-200向けにM6800アセンブリで作り直しました。番号の作り方、EXACT/NEARの数え方、
直近6回の記録、10回の上限は上流と同じです。

## 目的と勝敗

- ダイヤルを合わせて`RETURN`で試すと、EXACT（数字も位置も合っている数）とNEAR（数字は合っているが
  位置が違う数）が出ます。番号の同じ1桁を二重には数えません。
- 4桁すべてが合う（EXACT 4）と扉が開いてクリアです。
- 10回試しても開かないと失敗（`TEN CODES DID NOT OPEN VAULT`）です。
- 10面をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

各面の番号は、面が始まった時点のタイトル曲の進み具合（上流の`entropy()`に当たる値）と面の番号から決まります。

## 操作

| key | 動作 |
| --- | --- |
| `A` / `D` | ダイヤルを選ぶ（左右で循環） |
| `W` / `S` | 数字を1〜4で回す（循環） |
| `RETURN` | 今の番号を試す |
| `SPACE` | この面のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

判定が1桁ずつ進む演出と、扉が開く演出が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- 最初に1122のように2種類の数字を試すと、どの数字が含まれるかが絞れます。
- 以前の結果と矛盾しない番号だけを試すと、どの番号も6回以内に開けられます。
- 画面の記録（LAST SIX CODES）は直近6回です。

## 画面（色と記号）

| もの | 色 | 形 |
| --- | --- | --- |
| 数字1／2／3／4 | 赤／緑／黄／水色 | ダイヤルと記録の数字 |
| 選んだダイヤル | 黄 | 上に`V` |
| 回している途中 | 数字の色 | `-` |
| 判定中の桁 | 黄 | 下に`*` |
| EXACT | 緑 | 記録の右の数 |
| NEAR | 黄 | 記録の右端の数 |
| 金庫の扉 | 黄 | 3段階で細くなって開き、`VAULT OPEN` |

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ハ短調の3声の曲（音源F・D・Cを同時に使用、ループ） |
| ダイヤル・判定 | 短いクリック（音源C） |
| 判定の結果 | 2音の効果音（音源C） |
| クリア | 3声のハ長調アルペジオ |
| 失敗 | 3声の下がるハ短調の音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルです。面の開始時に取った値（origin）だけは
エミュレータの実行から`$4720`の記録として受け取り、それ以外のRAM期待値はすべてモデルが計算します
（上流の検査と同じ扱い）。解答は、矛盾しない最初の番号を試す方法で、全256通りを6回以内に開けます。
