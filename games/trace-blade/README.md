# TRACE BLADE

30の部屋を、一筆の刀筋で突破するパズルです。12×9マスの部屋で、左上の始点から経路を1マスずつ計画し、
すべての標的を通って出口で終わる経路ができたら、刀がその経路を走って標的を斬ります。
JR100devの`TRACE BLADE 1.6.1`（`games/trace_blade`）を仕様として、JR-200向けにM6800アセンブリで作り直しました。
上流はJR-100向けの手書きアセンブリで、Pythonのルールモデルがありません。この版の`tests/model.py`は
上流のアセンブリ（`PLAN_INPUT`、`ADD_STEP`、`UNDO`、`MENU_INPUT`、`EXECUTE`、`EXEC_TICK`、`RESET_PATH`）と
`check_rules.py`／`replay.py`から作った検証用モデルです。30部屋の地図と解答経路は上流の`levels.json`です。

## 目的と勝敗

- 始点（左上の刀）から`W`/`A`/`S`/`D`で経路を1マスずつ伸ばします。壁と、一度通ったマスには進めません。
- `SPACE`で1手ずつ戻せます。始点まで戻せます。
- 赤い菱形の標的をすべて経路に入れ（通った標的には四隅の印）、紫の出口で経路を終えたら、`F`で実行（CUT）します。
  条件を満たさない実行や、進めない方向への移動は`CHECK PATH AND ALL TARGETS`と表示され、何も変わりません。
- 実行すると、刀が経路を1マスずつ（上流と同じ5フレームごと）走り、標的を光・破片・粒の3段で斬ります。
  すべて斬ると部屋の突破です。30部屋を突破するとクリアです。失敗はありません。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 1つ目の部屋から始める |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| 計画 | `W` / `A` / `S` / `D` | 経路を上下左右に1マス伸ばす |
| 計画 | `SPACE` | 1手戻す |
| 計画 | `F` | 実行（CUT） |
| 計画 | `RETURN` | メニュー（CUT／UNDO／RESET／TITLE／BACK） |
| メニュー | `W` / `S` | 選ぶ（端で反対側へ回る） |
| メニュー | `RETURN` | 決定 |
| メニュー | `SPACE` | 閉じる |
| RESET？／TITLE？ | `A` / `D` | YES／NO（最初はNO） |
| RESET？／TITLE？ | `RETURN` / `SPACE` | 決定／取り消し（メニューへ戻る） |
| 突破後 | `RETURN` | 次の部屋 |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

RESETはその部屋の経路を消し、TITLEはタイトルへ戻ります。上流と同じく、どちらも確認でYESを選んだときだけ実行します。
上流では突破後に任意のキーで次へ進みますが、この版は共通の進行に合わせて`RETURN`です。

## 最初の目標と序盤のコツ

- 右の`TARGET`は標的の数、`MARKED`は経路に入れた数、`PATH`は歩数、`COMBO`は実行中に斬った数です。
- 出口は通り抜けられますが、経路の最後は出口でなければなりません。行き止まりに入ったら`SPACE`で戻ります。

| 場面 | 音 |
| --- | --- |
| タイトル | ホ短調の3声の行進曲（音源F・D・Cを同時に使用、ループ） |

## 速さ

上流の実行は60分の5秒（約0.083秒）ごとに1マス進みます。この版は固定エミュレータで1マス約12.5万cycle（描画を含み約0.093秒）、
標的1つの斬撃は3段で約27万cycleです。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$3FFF`、作業領域は`$4000-$5FFF`（専用stackを含む）、自己試験の結果は`$6000`以降です。
30部屋の地図と自己試験の経路でコードが8KBを超えるため、作業領域を他の作品より`$1000`上に置いています。

## 開発と自己試験

タイトルで`T`を押すと、`tests/selftest.py`の9件のfixture（状態を置いて1操作：壁、通ったマス、早すぎる実行、
始点での戻し、メニューの開閉と回り込み、RESETの確認）と、30部屋それぞれの上流の解答経路と実行（`F`）を、
描画せずにプログラム内で実行し（`sdk/selftest.inc`）、各結果の先頭118 byte（状態と地図）を`$6000`以降へ書き出します。
`tests/expectations.json`の期待値は`tests/model.py`と`tests/selftest_model.py`が計算した値で、エミュレータの出力を写したものではありません。
全30部屋を通常の速さで再生すると固定runnerの上限（3億cycle）に近いため、通常速度の再生は最初の10部屋（`synthetic-ten-rooms`）です。
`src/rooms.inc`は`python3 games/trace-blade/tests/make_rooms.py`、`src/selftest.inc`は`python3 tests/make_selftest.py trace-blade`で生成します。
