# CARGO BALANCE

12個の荷物を4つの船倉へ積み、船を傾けずに出航させるゲームです。全6航海です。
JR100devの`CARGO BALANCE 2.0.0`（`games/cargo_balance/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。荷物の順番、船倉ごとの力（トルク）、風、許容差（LIMIT）、運賃は上流と同じです。

## 目的と勝敗

- クレーンを4つの船倉の上へ動かし、次の荷物（重さ1〜3）を落とします。1つの船倉には4個まで積めます。
- 外側の船倉（左端・右端）は運賃（FARE）が2倍ですが、船を傾ける力は内側の3倍です。
- 左舷（PORT）の力に風（WIND）を足した値と右舷（STARBOARD）の力の差がLIMITを超えると転覆して失敗
  （`THE LOAD TIPPED THE SHIP`）です。
- 風は航海ごとに0・1・2の順、LIMITは10から2航海ごとに1ずつ下がります。
- 12個を積み終えるとクリアです。6航海をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| key | 動作 |
| --- | --- |
| `A` / `D` | クレーンを動かす（4つの船倉で循環） |
| `RETURN` | 荷物を落とす |
| `SPACE` | この航海のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

荷物が落ちて船が揺れる演出が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- NEXTに次の2個の重さが出ます。重い荷物が続くときは、先に内側で釣り合いを取っておきます。
- 外側に積むと運賃は増えますが、1個で3倍の力がかかります。左右の外側を交互に使うと釣り合いを保ちやすくなります。
- 風のある航海では、はじめから左舷側が重い扱いです。右舷を少し重くしておきます。

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ト長調の3声の舟歌（音源F・D・Cを同時に使用、ループ） |
| 荷物を落とす | 短い2音（音源C） |
| 積み込み | 2音の効果音（音源C） |
| 船倉が満杯 | 低い2音（音源C） |
| クリア | 3声のト長調アルペジオ |
| 失敗 | 3声の下がる音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
各航海の積み方は、転覆しない手順をモデルの探索（`plan()`）で求めています。
