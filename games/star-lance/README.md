# STAR LANCE

左右に行進しながら迫る18隻の艦隊を、軽い弾と重い弾で撃ち落とすシューティングゲームです。全6波です。
JR100devの`STAR LANCE 4.0.0`（`games/star_lance/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。艦隊の行進と降下、装甲のある前列、狙って撃つ敵の充填と誘導弾（3波目から3発）、
軽い弾・重い弾、武器の熱と過熱、撃つ直前の敵を倒したときの冷却、船体とシールドは上流と同じで、
上流の1 tickをこの版の1 tickとして移しています。

## 目的と勝敗

- `A` / `D`を押し続けて船（ランス）を左右に動かします。`RETURN`で軽い弾（1ダメージ、熱+3）、`W`で重い弾（2ダメージ、熱+5）を撃ちます。
- 熱（HEAT）が12になると28 tickの間撃てません（`COOLING`）。熱は時間とともに下がります。
- 敵は1隻を選んで点滅しながら充填し、船へ向けて弾を撃ちます（3波目からは左右にも1発ずつ）。点滅中の敵を倒すと熱が4下がり（`COOL +4`）、撃たれません。
- 前列（4波目からは2列）の敵は装甲があり、2ダメージで倒れます。
- 敵の弾に当たると船体（HULL）を1失い、しばらく無敵になります。3つ失うか、艦隊が6段降りてくると失敗です。
- 18隻をすべて倒すと波のクリアです。6波目をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| 場面 | key | 動作 |
| --- | --- | --- |
| タイトル | `RETURN` | 1波目から始める |
| タイトル | `P` | 1波目の自動デモ（`DEMO`表示） |
| タイトル | `T` | 開発用の自己試験（下記） |
| タイトル | そのほか | 説明 |
| 波 | `A` / `D`（押し続ける） | 左右に動く |
| 波 | `RETURN` / `W` | 軽い弾／重い弾 |
| 波 | `SPACE` | やり直し（確認あり） |
| クリア後 | `RETURN` | 次の波 |
| 失敗後 | `RETURN` | やり直し確認 |
| どこでも | `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

押し続けの判定はキーボードMCUの走査（`sdk/keyscan.inc`）で読みます。JR-200のMCUは押しているキーを1つだけ返すため、
移動しながらの射撃は、キーを押した瞬間（上流と同じく次のtickまで保持）で行います。

## 最初の目標と序盤のコツ

- 点滅している敵を先に倒すと、撃たれずに熱も下がります。
- 装甲のある前列には重い弾を使います。熱が高いときは軽い弾でつなぎます。

## 速さ

上流は4/60秒（約0.067秒）に1 tickです。この版は、固定エミュレータで1 tickが約9.5万cycle（約0.071秒、描画とキー走査を含む）です。
被弾の演出の間はtickが止まります。

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$64FF`（専用stackと自己試験の結果を含む）です。
ROMなしの固定エミュレータでは、キー走査の初期化に約130万cycleかかるため、試験の操作はその後に始めます。

## 開発と自己試験

tickとキーの時間関係はcycleに依存するため、ルールの一致はプログラム内の自己試験で確かめます
（`sdk/selftest.inc`）。タイトルで`T`を押すと、`tests/selftest.py`の34件のfixture（状態を置いて1 tickまたは1操作）と、
6波それぞれの入力スクリプト（tickに同期した押しているボタンの組）での通し遊びを実行し、結果を`$5000`以降へ書き出します
（爆発の表示位置を除く131 bytes）。
`tests/expectations.json`の期待値は`tests/model.py`（上流`rules.py`のPythonモデル）と`tests/selftest_model.py`が計算した値です。
スクリプトはモデル上で「狙いを合わせ、弾の着地点を避ける」方針で作り、6波すべてを被弾なしでクリアします。
`P`の自動デモは1波目のスクリプトを通常の速さで再生します。
`src/selftest.inc`は`python3 tests/make_selftest.py star-lance`で生成します。
