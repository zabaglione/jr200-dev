# RUIN LEXICON

遺跡の碑文に刻まれた3つの和と1つの大小関係から、4つの文字（A〜D）に1〜4の数字を1つずつ割り当てる謎解きです。全20碑文です。
JR100devの`RUIN LEXICON 2.1.0`（`games/ruin_lexicon/rules.py`）を仕様として、JR-200向けに
M6800アセンブリで作り直しました。碑文の表、数字の回し方、1文字ずつの照合、5回の試行は上流と同じです。

## 目的と勝敗

- 左の碑文にA+B、B+C、C+Dの和と、AとDの大小（`<`／`>`）が出ます。
- 右の辞書で各文字に1〜4を割り当て、`RETURN`で照合します。4つとも合えばクリアです。
- 外れると試行（TRIES）が1減り、碑文の各和の横に、今の割り当てで合う和は`*`、合わない和は`X`が付きます。
- 5回外すと失敗（`FIVE DICTIONARIES REJECTED`）です。20碑文をクリアすると`ALL STAGES CLEAR - THANK YOU`で終わります。

## 操作

| key | 動作 |
| --- | --- |
| `A` / `D` | 文字を選ぶ（4つで循環） |
| `W` / `S` | 数字を1つ上げる／下げる（1〜4で循環） |
| `RETURN` | 照合する |
| `SPACE` | この碑文のやり直し確認。初期選択はNO、`A`/`D`で選び`RETURN`で確定 |
| `ESC` / `CTRL+C` | ゲームを終えてBASICへ戻る |

数字が回る演出と、4文字を順に照合する演出が終わってから次のキーを押してください。

## 最初の目標と序盤のコツ

- 1〜4を1つずつ使うので、4つの合計は必ず10です。A+BとC+Dの和から、B+Cの和の意味を考えます。
- 和が3ならその2文字は1と2、和が7なら3と4です。
- 最後にAとDの大小で、残った2通りから1つに決まります。

## 画面（色と記号）

| もの | 色 | 形 |
| --- | --- | --- |
| 碑文の石 | 青の地 | 文字は黄、`+` `=`は白、和と大小は水色 |
| 合う和・合わない和 | 緑・赤 | `*`・`X` |
| 辞書の石板 | 紫の地 | 文字は白、数字は黄。回している数字は`-` |
| 選んでいる文字・照合中の文字 | 黄 | `>`・`*` |
| 試行の残り | 白。残り1で赤 | 数字 |

## 音

| 場面 | 音 |
| --- | --- |
| タイトル | ニ・ドリアの3声の古い聖歌風の曲（音源F・D・Cを同時に使用、ループ） |
| 数字を回す・照合する | 短い音（音源C） |
| 外れ | 低いブザー（音源C） |
| クリア | 3声のニ長調アルペジオ |
| 失敗 | 3声の下がる音型 |

## 起動

1. CJRを通常の`MLOAD`で読み込みます。
2. BASICから`A=USR($1000)`を実行します。
3. 終了後はBASICへ戻り、画面・ユーザー文字・文字RAM・キー制御ポートは起動前の状態に戻り、3つの音源は止まります。

標準のRAM構成で、ロード先は`$1000-$2FFF`、作業領域は`$3000-$4FFF`です。

## 開発

```sh
JRASM=/absolute/path/to/jrasm make build
RUNNER_BUNDLE=/absolute/path/to/emulator/bundle make run
```

`tests/model.py`は上流`rules.py`を写したPythonモデルで、`tests/expectations.json`のRAM期待値を計算します。
各碑文の答えは、画面に出る3つの和と大小だけから`solve()`で求めています（上流の20碑文はすべて答えが1通りです）。
